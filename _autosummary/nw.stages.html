nw.stages#

Stages: the plain-English steps of a kind of production, owned by the engine (reelee#458).

A stage is a fact about a kind of production (short film, music video, podcast), not about a screen: “Make the reference images” is several transforms, and a person means the whole. Before this module the stage list existed only as display text in an app, so “Step 3 of 6”, the stage list and the banner total could disagree and none of them was real.

One source, three derived facts, each with a single owner:

  • Declaration — Stage, on nw.Genre.stages (pure data: a plain-English name, whether it is free, and the transform_names / body_schema_uris that carry it out or evidence it).

  • State — stage_states(), derived from the graph and never stored: not_started (nothing produced), in_progress (something produced but stale, or a job for one of its transforms is running), done (produced, none stale), or unknown (the stage names nothing the graph could show, so we do not guess). Staleness is nw.freshness.stale_verdicts_all()’s; the rule is not restated. The graph cannot say how many outputs a stage should have (how many shots), so done means “has output and none of it is out of date”, and the app can pass active_transforms to say a stage is mid-run.

  • Price — stage_prices(), composed at ask time from a caller-supplied quote (the app builds the plan; nw.current_quote() re-prices it, the nw#74 rule). A free stage is 0.0 because it was declared free; a stage nobody can quote is None — unknown, never free.

stage_overview() is the one JSON-able answer every surface reads, so the step list, “Step N of M” and the banner total cannot disagree. The remaining total is None when any unfinished paid stage is unknown: a missing total beats a wrong one (reelee-web#305).

>>> from nw.genres import Genre
>>> g = Genre(slug="demo_stages", title="Demo", transform_names=("a.t",),
...           stages=(Stage("idea", "The idea", free=True),
...                   Stage("make", "Make it", transform_names=("a.t",))))
>>> [s.name for s in g.stages]
['The idea', 'Make it']
>>> stage_prices(g.stages, lambda s: 1.5)[1].total_usd
1.5
>>> stage_prices(g.stages, lambda s: None)[1].status
'unknown'

nw.stages.stage_overview(genre, project, *, quote=None, active_transforms=())[source]#

The one JSON-able answer: stages with state and price, “Step N of M”, and the total still to spend. genre is an nw.Genre or its slug.

step is the 1-based position of the first stage not done (of when all are). remaining_total_usd sums the price of every stage not done and is None when any of them is unknown.

Return type:

dict

nw.stages.stage_prices(stages, quote=None)[source]#

Compose each stage’s price now. quote(stage) returns USD, an nw.PlanQuote (its total_usd), or None; no quote means every paid stage is unknown. A raising quoter is unknown too: a price we could not work out is not a price.

Return type:

list[StagePrice]

nw.stages.stage_states(stages, project, *, active_transforms=())[source]#

Where project stands in each of stages, read from its graph.

project is anything the graph surfaces accept (a path, a storage, a nw.Project). active_transforms are transform names with a job running now, which the graph cannot know; a stage that owns one is in_progress.

Return type:

list[StageState]
