nw.media_store#

One content-addressed blob store per user, shared by every genre and host (nw#95).

Before this, each genre kept its own copy of a project’s media (~/.local/share/ {muvid,braidio,reelee*}) and each host instance (staging, dev) held a full copy of the same project. This module is the one place the bytes live.

Decisions (owner-confirmed on reeleehq/nw#104; recommendations in nw#95):

  1. Layout — <root>/<tenant>/<lifecycle_class>/<sha256>, with root = ~/.local/share/nw/media (nw owns the writer, so nw owns the data home). tenant is local on a workstation and a caller’s hashed id when hosted.

  2. Blobs are keyed by content; rows are not. Five renders with identical bytes are one blob and five rows, each with its own name, project and provenance. Nothing a user sees collapses; only the disk copy does. (This is the amendment to reelee’s docs/adr_asset_surfaces.md §6.)

  3. Hosts share blobs, keep a catalog each. A host opts in by naming the store (HostArtifactCatalog(..., store=...)). The host keeps reading its own blobs/<sha256>; that entry is a hardlink to the store’s blob, so nothing is copied and the host is unchanged.

Garbage collection (SharedMediaStore.sweep()) marks from every catalog registered with the store, never one host’s. It is two-phase: a blob with no live row anywhere is first marked (a timestamp), and only removed by a later sweep once it has stayed unreferenced for grace_s; a row appearing in the meantime clears the mark. It is a dry run unless apply=True. It refuses to run if a registered catalog’s rows directory is missing or unreadable, because an unreadable catalog cannot vouch for its blobs (unregister_catalog is the explicit way to retire one). Reference count = the number of live rows naming a blob (references()).

>>> import tempfile, pathlib
>>> with tempfile.TemporaryDirectory() as d:
...     store = SharedMediaStore(pathlib.Path(d, "store"))
...     src = pathlib.Path(d, "a.bin"); _ = src.write_bytes(b"abc")
...     aid = store.put(src)
...     store.has(aid), store.blob_path(aid).parent.parts[-2:]
(True, ('local', 'project'))
