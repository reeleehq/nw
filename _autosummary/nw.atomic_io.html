nw.atomic_io#

Small-file IO that a concurrent reader can never catch half-done (nw#243, nw#260).

nw’s stores (the shared media store’s registry, the host media catalog’s rows) keep small JSON/text files that a writer replaces while readers poll them. Three helpers, all through dol.atomic:

  • write_text_atomic(): temp file, then os.replace, so a reader sees the old text or the new, never a truncated file;

  • copy_file_atomic(): a whole file copied into place the same way (a blob copied across filesystems), on dol’s uniquely named O_EXCL temp, so two copies of one blob at once never share a temp file;

  • replace_retrying(): os.replace alone;

  • read_text_retrying(): a read.

Each retries a Windows sharing violation (a reader or writer holding the file for an instant), the policy retry= (keyword-only; default dol.atomic.DFLT_RETRY, which retries nothing off Windows, where the same error means a real permission problem). A missing file is never retried. Stdlib and dol only, so any module can use it.
