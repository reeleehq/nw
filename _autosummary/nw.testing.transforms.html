nw.testing.transforms#

Conformance check: a Transform’s result says truthfully what it wrote (nw#234).

nw.transforms.TransformResult.reused_ids is an obligation on an overriding execute: report every returned node it did not write in this call (nw#215). nw cannot check that at runtime (overrides legitimately mint ids), but a Transform author’s test can:

from nw.testing.transforms import recording_writes

with recording_writes(project) as writes:
    result = my_transform.execute(project, plan, skeleton)
writes.check(result)  # AssertionError naming every misreported row

A row counts as written in the call when its id is new, its content changed (body, generation stamp or tier: an in-place entity upsert counts), or a verifying trace naming it was recorded during the call (a derived node re-written unchanged; nw’s add_annotation records one per write, under a fresh id). What counts is fixed when the with block exits. WriteRecord.check() asserts every result.written row was, and every result.reused_ids row was not. Run it over a host’s registered Transforms, the way nw pins every execute signature.

check(result, *, require_traces=True)[source]#

Raise AssertionError unless result.written / result.reused_ids tell the truth (a real raise, so python -O cannot skip it).

require_traces (default True) also flags a written derived row (one with was_derived_from parents) that got no verifying trace in the block: written by a raw store.add, or by add_annotation with a parent it could not resolve or digest, it reads stale forever (nw#271). Only rows the result reports are scanned; a derived row written but not reported is out of this check’s reach.

Return type:

None
