Source code for nw.jobs

"""nw.jobs — a project-scoped async **job** facade over ``au``.

A "job" is one long, cancellable unit of render work (a full-auto journey, a
single ``panel.animate``, an ``assemble_animatic`` pass, …). It has a durable
id, a persistent terminal state, live progress + ETA, a cost, and a cancel
entry keyed by that id — everything a task tray needs and none of which a bare
HTTP request provides.

This module is the *only* place async substance lives for the render layer:
``au`` supplies the submit → poll → result skeleton and the durable store;
``nw.jobs`` adds the five render-domain concerns ``au`` has no data model for —
progress %, ETA, human label/kind, idempotency (dedup), and cost — plus the
5-state normalization, context-capture so a job outlives its request, and the
active-jobs index that makes membership meaningful. Consumers (reelee's
``/api/jobs`` closures) stay thin: they call :func:`enqueue` / :func:`estimate`
/ :func:`list_jobs` / :func:`get_job` / :func:`cancel_job` / :func:`to_dict`
and serialize the result.

Design decisions (from the ``nw.jobs``-on-``au`` design report,
``misc/docs/research/async-job-manager-on-au.md``):

- **Backend = ``au.ThreadBackend``**, not ``ProcessBackend``. A fal render is
  I/O-bound (a blocking upstream wait), and the worker must share the live
  in-process ``Project`` graph and write events to the same channel the
  existing SSE tails. Process isolation buys no real fal cancel (fal still
  bills) while breaking the live-progress channel. Where bounded concurrent
  paid renders matter, swap in ``StdLibQueueBackend(use_processes=False)`` —
  a construction detail behind this facade.
- **au store is SSOT for *status* only.** ``ThreadBackend`` overwrites the
  store record with a bare ``ComputationResult`` at start (RUNNING) and end
  (COMPLETED), carrying no metadata — so every job-semantic field lives in a
  per-project **active-jobs index** (a ``dol`` mapping), which ``au`` cannot
  clobber. The index is also the membership authority: ``au.FileSystemStore``
  synthesizes ``PENDING`` for a missing key, so store membership is
  meaningless.
- **Idempotency**: the au store key *is* the idempotency key
  (``sha256(project:kind:plan_hash-or-params)``). A resubmit while a job with
  that key is live returns the existing job instead of launching a duplicate.
- **Cancel is boundary-grained and race-proof.** ``cancel_job`` flips the au
  record terminal *and* sets a durable should-cancel flag; the ``cancel_requested``
  flag is the authority for cancellation intent, so a job reads
  ``cancelling`` → ``cancelled`` regardless of whether the still-running
  ``ThreadBackend`` thread later clobbers the store with COMPLETED. The key
  stays live until that thread has exited, in this process or any replica
  sharing the store: each run carries a ``run_token``, its heartbeat stamps
  only its own record, and ``worker_exited_at`` is written once the run's
  outcome is in au's store — by the managed backend's middleware, or by the
  worker on any other backend (nw#124, nw#141, nw#149).
- **A job's end is announced** to :func:`register_terminal_hook` hooks, so a
  host records a completion in one place instead of after every door (nw#151).
- **ETA is learned from observed wall-time**, per ``(model, operation, dur_bucket)``
  with back-off, median (not mean), honest "estimating…" before enough
  history, and **cache-hits excluded from learning**.
- **A cost never travels without its honesty flag.** ``JobCost.actual_usd`` is
  paired with ``actual_is_lower_bound``, because an unpriceable call that
  actually billed contributes ``0.0`` to the sum — so a bare ``$0`` means
  *either* "nothing was spent" *or* "we do not know what was spent", and a
  spend surface that cannot tell them apart shows the second as free.
- **An estimate is re-quoted, never remembered.** When ``params["plan"]`` is
  supplied, :func:`estimate` and :func:`enqueue` price it through
  :func:`nw.pricing.current_quote` at today's rates rather than trusting a
  caller-supplied ``estimated_usd`` frozen at plan time — falaw's rate tables
  move, and a stale figure under-quotes the run (nw#74). Descriptive only:
  ``cost_basis`` stays out of ``plan_hash``, so the idempotency key above is
  byte-identical to what it was before repricing existed, and a resumed render
  still dedups onto work already paid for. A host that prices server-side
  passes ``enqueue(..., estimated_usd=)`` instead: recorded as the job's
  estimate, and outside ``params`` so it never enters the job id (nw#144).

All tunables are keyword-configurable via :class:`JobsConfig`; defaults live at
the top of this module — no magic numbers below.
"""

class JobsConfig:
    """Tunables for the job manager. All keyword-configurable; sensible defaults.

    ETA knobs (``n_min`` … ``prior_total_s``) mirror the design report §5.7.
    """

    n_min: int = 3
    """Minimum samples for a key before its prediction is ``"learned"`` (not prior)."""
    sample_window_k: int = 20
    """Keep only the most-recent K duration samples per key (robust to drift)."""
    pct_ceil: int = 99
    """Never *compute* 100% — only the → succeeded transition sets 100."""
    overrun_factor: float = 1.5
    """Synthesize ``p90 = p50 * overrun_factor`` when a real p90 isn't available."""
    cache_hit_floor_s: float = 0.5
    """Predicted total for an all-cache-hit plan (``confidence="exact"``)."""
    dur_buckets_s: tuple[float, ...] = (4.0, 8.0, 12.0)
    """Upper edges of the output-duration buckets for ``per_second`` models."""
    prior_total_s: Mapping[str, float] = field(
        default_factory=lambda: {"image": 12.0, "video": 90.0, "audio": 15.0}
    )
    """Cold-start priors by output kind (drives the honest "estimating…" label)."""
    default_prior_total_s: float = 30.0
    """Prior when even the output kind is unknown."""
    stale_running_s: float = 900.0
    """A RUNNING record older than this with no live worker is reaped as
    ``FAILED("worker died — resumable")`` (kills the stuck-toast bug)."""

    heartbeat_interval_s: float = 20.0
    """How often a running worker stamps ``heartbeat_at`` on its index record.

    Liveness has to be a fact in the **shared store**, not in one process's
    memory, or a second API replica cannot tell a live job from a dead one.
    Cheap: one small atomic file write per job per interval."""

    heartbeat_stale_s: float = 120.0
    """A heartbeat younger than this proves the worker is alive **anywhere**.

    Generously larger than ``heartbeat_interval_s``: the beat is a Python
    thread, and a render holding the GIL in a C extension can delay it well
    past one interval. The asymmetry is deliberate — a late beat costs a
    slower reap, while an eager one destroys a live job's record."""
    terminal_hook_attempts: int = 3
    """How many announcements of one run a failing terminal hook gets before
    nw gives up on it (logged once). Hooks that already succeeded for the run
    are not called again, so a broken hook never makes the healthy ones re-fire
    on every poll."""
    terminal_hook_lease_s: float = 300.0
    """How long a claim to announce a run excludes every other claimant, this
    replica's threads included (the ``announce_claim`` lease on its record).

    Well above a slow hook: a lease that expires while its hooks still run lets
    a second claimant announce the run again. A claimant that crashed mid-hooks
    holds the run this long, then the next read retries it. Replicas' clocks
    are assumed to agree to well within it, as for ``heartbeat_stale_s``."""
    approval_threshold_usd: float = 1.0
    """Estimated cost at/above which a render requires explicit approval."""
    index_retention_s: float | None = 30 * 24 * 3600.0
    """A finished, announced run whose end is older than this leaves the live
    index for the archive when :func:`list_jobs` next scans it (nw#169), so
    the scan, and every poll, stays bounded by recent work instead of growing
    with the project's whole history. :func:`get_job` and :func:`cancel_job`
    still answer for an archived id. ``None`` keeps every run in the index."""
    never_started_after_s: float | None = None
    """A run still queued this long after it was created (never started: au
    PENDING or no au entry, no ``started_at``), with no worker here or beating
    anywhere, is failed as ``NEVER_STARTED_REASON`` by the archive sweep
    (nw#174), so an orphaned record (nw#117) ends instead of lingering.
    ``None`` (default): a queued run is never failed for waiting, since a
    custom backend's queue can be long, and a run that starts after being
    failed writes RUNNING over FAILED after its failure was announced."""
    index_sweep_interval_s: float | None = 3600.0
    """How often (per process and project) :func:`list_jobs` looks for runs to
    archive, so the look is not repeated on every poll. ``None``: never; the
    host schedules :func:`archive_finished_runs` instead (nw#174)."""
    jobs_dirname: str = ".nw/jobs"
    """Sub-path under ``project.root`` for the job stores (nw's ``.nw/`` convention)."""

class JobCost:
    estimated_usd: float | None = None
    """Predicted spend, re-quoted at today's rates when a plan was supplied.

    ``None`` means unknown, and unknown always requires approval — it is what
    a plan whose calls carry no :class:`falaw.CostBasis` re-prices to. Never
    the plan-time figure passed in alongside such a plan: that number was true
    when it was written and falaw's rate tables have moved since (nw#74).
    """
    actual_usd: float | None = None
    cache_hit_savings_usd: float | None = None
    actual_is_lower_bound: bool | None = None
    """True when the run reported ``has_unknown_costs`` — some call that
    actually billed had no price, so :attr:`actual_usd` UNDER-states the spend.

    Its whole job is to keep a ``$0`` readable. Without it, ``actual_usd``
    conflates two answers a spend surface must never merge: "this run cost
    nothing" (a cache hit — a known zero) and "we do not know what this run
    cost" (an unpriceable call ran). A UI that renders the second as *free*,
    or a bound that reads it as *under budget*, is the failure this field
    exists to make impossible.

    ``None`` means the render never reported either way — an older caller, or
    a job that died before finishing. ``None`` is not ``False``: absence of the
    flag is not a claim that the total is exact.
    """

def enqueue(
    project,
    kind: str,
    params: dict,
    *,
    on_event: Callable[[Any], None] | None = None,
    dispatch: Mapping[str, Callable] | None = None,
    backend: ComputationBackend | None = None,
    idempotency_key: str | None = None,
    label: str | None = None,
    capture_context: Callable[[], AbstractContextManager[Any]] | None = None,
    secrets: Mapping[str, str] | None = None,
    estimated_usd: float | None | object = _UNSET,
    config: JobsConfig = DEFAULT_CONFIG,
) -> Job:
    """Enqueue a billable render as a background job. Returns a :class:`Job`
    (``status="queued"``) **immediately** — the call never blocks and never
    bills on the calling thread.

    The request context (fal credentials + the resolved ``Project``) is
    captured now and re-established inside the worker so the job outlives its
    request. If a *live* (non-terminal) job with the same ``idempotency_key``
    already exists, that job is returned instead of launching a duplicate.

    Args:
        project: the ``nw.Project`` the render operates on.
        kind: dispatch key selecting the render callable (e.g.
            ``"journey.full_auto"``, ``"panel.animate"``).
        params: render parameters (also the ETA-key + default-idempotency
            basis). A ``"plan"`` entry must be a **``falaw.plan_to_dict``
            dict, not a live** :class:`falaw.Plan`: the whole ``params``
            mapping is JSON-serialized into the job index, so a ``Plan``
            object raises there. The dict hashes to the identical
            ``plan_hash`` (:func:`_plan_for_identity`) and re-quotes the same
            way, so nothing is lost by serializing it — :func:`estimate`,
            which never writes a record, accepts either. A ``"units"`` entry
            (a positive ``int``) says how many ``output_kind`` units the
            job's wall-time covers — ``4`` for four image renders. Only a job
            that declares it teaches the shared coarse ``output_kind`` ETA
            bucket, per unit (nw#67); see :class:`DurationLearningMiddleware`.
        on_event: sink for the render's lifecycle events (reelee wires this to
            its ``agent_log`` / SSE tail). Events are stamped with
            ``job_id``/``run_id`` and mirrored into progress/cost/eta.
        dispatch: ``{kind: callable}`` table. Each callable is invoked as
            ``callable(project, params, *, job_id, on_event, should_cancel)``
            (only the kwargs it declares are passed) and should return a
            JSON-serializable result payload.
        backend: advanced override; default is the managed ``ThreadBackend``
            (which carries the duration-learning middleware + liveness map).
        idempotency_key: dedup handle; default derived from ``falaw.plan_hash``
            of ``params["plan"]`` when present, else a stable hash of params.
        label: human tray label; default derived from ``kind``/``params``.
        capture_context: optional caller-supplied context hook. Called **now**
            (on the request thread) to snapshot any request-scoped state the
            caller needs re-established inside the worker, returning a context
            manager entered around the render on the worker thread. ``nw.jobs``
            handles fal credentials itself (``falaw`` is its dependency); this
            hook is how a caller re-binds credentials it owns without ``nw``
            importing them — e.g. reelee's BYO vision (aix) + ElevenLabs keys,
            which otherwise fall back to owner/env in a background job because
            ``ThreadBackend`` does not copy ``ContextVars`` into the worker.
            The hook runs **under the runtime's non-reentrant lock**
            (``rt.lock``, which also holds every other replica sharing the
            jobs root out of the index), so it must be quick and must not call
            back into ``nw.jobs`` (``enqueue``, ``get_job``, ``cancel``…): that
            would deadlock. If ``backend.launch`` then fails, the returned context
            manager is entered and exited once, so anything it acquired in the
            call itself is released (outside the lock, so its ``__enter__``/
            ``__exit__`` run once, on the request thread); it is otherwise
            entered only by the worker.
        secrets: the caller's per-call credentials (:class:`nw.Secrets`; any
            mapping is coerced), for a render that spends a bring-your-own
            key. Held **in memory only**: never written to the job index
            (``params`` is — never put a key there), never logged, and it
            reaches the render callable only when that callable declares a
            ``secrets`` keyword — the same accepts-it-or-not rule as
            ``job_id`` / ``on_event`` / ``should_cancel``. A ``"fal"`` secret
            is also bound as the worker's fal credential
            (:func:`nw.secrets.using_secrets`), innermost, so an explicit key
            wins over an ambient one. The explicit counterpart of
            ``capture_context``: what that hook re-binds ambiently, this
            threads by hand.
        estimated_usd: the price the **host** computed for this job, recorded
            as its ``cost.estimated_usd`` in place of nw's own (the plan
            re-quote, else ``params["estimated_usd"]``, which a client may
            have chosen). ``None`` records *unknown*. Not part of ``params``,
            so it never enters the job id: a price that drifts with the graph
            does not split dedup, and a dedup onto a live job keeps that
            job's figure (nw#144). Omitted, nothing changes.
        config: tunables (see :class:`JobsConfig`).

    Raises:
        KeyError: if ``kind`` is not in ``dispatch``.
        ValueError: if ``params["units"]`` is present but not a positive ``int``,
            or ``estimated_usd`` is neither ``None`` nor a finite, non-negative
            number (see :func:`checked_usd`).
    """
    if estimated_usd is not _UNSET:
        estimated_usd = checked_usd(estimated_usd)
    rt = _runtime(project, config)
    dispatch = dispatch or {}
    idempotency_key = idempotency_key or _default_idempotency_key(project, kind, params)
    job_id = idempotency_key  # the au store key IS the idempotency key
    label = label or _default_label(kind, params)
    units = _eta_units(params)
    eta_candidates, output_kind = _eta_candidates(params, config)

    unentered = None
    replaced = None  # ``(Job, run_token)`` of a finished run replaced unannounced
    try:
        with rt.lock:
            # An archived run of this key (nw#169) is the finished run a re-run
            # replaces, exactly as if it were still in the index.
            existing = _index_get_locked(rt, job_id) or rt.archive.get(job_id)
            if existing is not None:
                au_result = rt.au_store[job_id]
                status = _normalize_status(
                    au_result.status,
                    cancel_requested=existing.get("cancel_requested", False),
                )
                # A cancelled job reads terminal while its thread may still be
                # running (cancel is cooperative). Launching over it would hand
                # the new record to a worker that never sees its own
                # ``cancel_requested`` and writes its events/result into the new
                # job, so the key stays live until that thread has exited (nw#124),
                # wherever it runs (nw#141).
                if status not in TERMINAL_STATUSES or _worker_may_still_run_locked(
                    rt, existing, config
                ):
                    # Live job with this key already exists → dedup, run once.
                    return _project_job(rt, existing, au_result, config)

            callable_ = dispatch.get(kind)
            if callable_ is None:
                raise KeyError(
                    f"unknown job kind {kind!r} (dispatch has {sorted(dispatch)})"
                )

            run_token = uuid4().hex
            estimated, estimate_source = _estimate(params, host_usd=estimated_usd)
            record = {
                "job_id": job_id,
                "run_token": run_token,
                "worker_exited_at": None,
                "terminal_announced": False,
                "kind": kind,
                "label": label,
                "idempotency_key": idempotency_key,
                "params": _finite_json(params),
                "created_at": now_iso(),
                "started_at": None,
                "finished_at": None,
                "eta_candidates": [list(c) for c in eta_candidates],
                "output_kind": output_kind,
                "units": units,
                "expected_cache_hit": bool(params.get("expected_cache_hit", False)),
                "cached": False,
                "provider_phase": None,
                "provider_call_id": None,
                "provider_queue_position": None,
                "provider_started_at": None,
                "cancel_requested": False,
                "pct_floor": None,
                "progress": {},
                # Same gate, same rule: a supplied plan is re-quoted at today's
                # rates and its answer wins, so the tray never shows a frozen
                # figure as this job's price (nw#74). Its source rides along so
                # a render event cannot overwrite a host's own price (nw#144).
                "cost": {
                    "estimated_usd": estimated,
                    "estimate_source": estimate_source,
                },
                "artifact_ref": None,
                "result": None,
                "error": None,
                "error_kind": None,
                "error_detail": None,
                "last_event_id": None,
            }
            # Bind BEFORE the record exists: ``_bind_worker`` runs the caller's
            # ``capture_context`` hook, and a hook that raises must not leave a
            # "queued" record behind that no worker will ever pick up (nw#117).
            # The hook runs here, on the request thread, under ``rt.lock``.
            unentered = capture_context() if capture_context is not None else None
            the_backend = backend if backend is not None else rt.backend
            # Only a backend that will release them gets the liveness claim and
            # the worker-side announcement.
            backend_middleware = getattr(the_backend, "middleware", ())
            managed = rt.middleware in backend_middleware
            bound = _bind_worker(
                project,
                kind,
                params,
                callable_,
                job_id=job_id,
                on_event=on_event,
                rt=rt,
                config=config,
                extra_ctx=unentered,
                secrets=as_secrets(secrets),
                run_token=run_token,
                # The managed backend's middleware marks the exit after au's
                # terminal write (nw#149); any other backend, the worker does.
                mark_exit=not managed,
            )
            if existing is not None:
                # The fourth door: nothing read this run terminal yet (a custom
                # backend nobody polled, or a waiter re-enqueueing ahead of the
                # worker's end read), and replacing it would erase it (nw#151).
                old_job = _project_job(rt, existing, au_result, config)
                old_token = existing.get("run_token")
                # The claim stamps its lease on ``existing``, so a failed
                # launch restores the old run still claimed by this door.
                claim = _claim_announcement_locked(rt, existing, run_token=old_token)
                if claim is not None:
                    replaced = (old_job, old_token, claim)
            registered = False
            try:
                # Index first: a failed write then leaves the previous run whole.
                _index_set_locked(rt, job_id, record)
                if managed:
                    rt.middleware.claim_locked(job_id, run_token=run_token)
                if rt.announcer in backend_middleware:
                    rt.announcer.launch_locked(job_id, project)
                    registered = True
                if existing is not None:
                    # A re-run of a terminal key: the previous run's au result
                    # would otherwise be what this call (and any poll) reads
                    # until the new worker writes RUNNING — a fresh job reporting
                    # last run's terminal status (nw#120).
                    with suppress(KeyError):
                        del rt.au_store[job_id]
                the_backend.launch(bound, (), {}, job_id, rt.au_store)
                unentered = None  # a worker owns the context now
            except BaseException:
                rt.middleware.release_locked(job_id)
                if registered:
                    rt.announcer.release_locked(job_id)
                # Undo the swap, whichever step failed. A record with no worker
                # behind it reads as a live PENDING job to the next enqueue of
                # this key (au's store answers PENDING for a missing entry) and
                # is never reaped (nw#117); a re-run of a terminal key gets the
                # finished (possibly billed) run it replaced back (nw#124). The
                # au result goes back before the index, each step guarded, so a
                # store that is failing cannot leave a record without its result.
                if existing is None:
                    with suppress(Exception):
                        rt.index.pop(job_id, None)
                else:
                    with suppress(Exception):
                        rt.au_store[job_id] = au_result
                    with suppress(Exception):
                        _index_set_locked(rt, job_id, existing)
                raise
            # After the launch, outside its rollback: the index holds this key's
            # run again, and a failure here must not undo a launched worker.
            with suppress(Exception):
                rt.archive.pop(job_id, None)

    except BaseException:
        # No worker will ever enter the hook's context: release what it
        # acquired in the call itself, outside ``rt.lock`` (nw#120).
        _release_unentered(unentered)
        raise
    finally:
        # Outside ``rt.lock``: a hook may call back into ``nw.jobs``. A failed
        # launch restored the run, so the hooks' success marks it announced.
        if replaced is not None:
            old_job, old_token, claim = replaced
            _fire_terminal_hooks(rt, project, old_job, run_token=old_token, claim=claim)
    return _project_job(rt, record, rt.au_store[job_id], config)

def estimate(
    project,
    kind: str,
    params: dict,
    *,
    estimated_usd: float | None | object = _UNSET,
    config: JobsConfig = DEFAULT_CONFIG,
) -> dict:
    """Dry-run cost gate **without enqueueing**.

    Returns ``{estimated_usd, estimate_source, has_unknown_costs,
    approval_threshold_usd, requires_approval, quote}``. Unknown cost always
    requires approval (preserves the one-price-per-clip gate).

    **The gate quotes, it does not remember.** When ``params["plan"]`` is
    present its cost is re-quoted at today's rates through
    :func:`nw.pricing.current_quote`, and a caller-supplied
    ``params["estimated_usd"]`` is ignored — exactly as
    :func:`_default_idempotency_key` ignores it for the dedup basis. A
    persisted plan's figure is frozen at plan time, and falaw's rate tables
    move (0.0.46 re-quoted premium LLM calls tenfold upward), so gating on
    the stored number under-quotes the run: the one direction a spend
    decision must never err in (nw#74).

    A supplied plan that cannot be re-quoted — no ``cost_basis`` on its calls,
    an unparseable payload, a model that has left the catalogue — yields
    ``estimated_usd=None``, which requires approval. Refusing to name a price
    is the safe answer; repeating yesterday's is not.

    Without a plan the gate falls back to ``params["estimated_usd"]``, whose
    provenance nw cannot see; ``quote`` is then ``None`` to say so. When there
    *is* a quote it carries ``caller_estimated_usd`` — what the caller passed,
    reported beside today's number rather than discarded, so a surface can
    show the movement.

    ``estimated_usd`` is a host's own price, gated on exactly as
    :func:`enqueue` records it (``None`` = unknown); the quote is still
    reported beside it. ``estimate_source`` says which figure won:
    ``"host"``, ``"plan"`` (the re-quote) or ``"caller"``
    (``params["estimated_usd"]``), and ``None`` when there was none to take.

    Raises ``ValueError`` on a malformed ``params["units"]`` or
    ``estimated_usd``, exactly as :func:`enqueue` does, so the gate never
    approves what enqueue refuses.
    """
    _eta_units(params)
    if estimated_usd is not _UNSET:
        estimated_usd = checked_usd(estimated_usd)
    quote = _quote_params(params)
    estimated, estimate_source = _estimate(params, quote=quote, host_usd=estimated_usd)
    has_unknown = estimated is None
    threshold = config.approval_threshold_usd
    requires_approval = has_unknown or (
        estimated is not None and estimated >= threshold
    )
    return {
        "estimated_usd": estimated,
        "estimate_source": estimate_source,
        "has_unknown_costs": has_unknown,
        "approval_threshold_usd": threshold,
        "requires_approval": requires_approval,
        # The caller's own figure travels *inside* the quote rather than being
        # dropped: a surface that can say "you were quoted X, it is Y today"
        # is the point of re-quoting, and silently discarding X leaves nothing
        # to show the movement against.
        "quote": (
            {**quote.to_dict(), "caller_estimated_usd": _caller_estimated_usd(params)}
            if quote is not None
            else None
        ),
    }




def _caller_estimated_usd(params) -> float | None:
    """The ``estimated_usd`` the caller passed in, or ``None`` if none was.

    Reported, never trusted: when a plan is supplied this number loses to the
    re-quote, and nw cannot see where it came from.

    A figure :func:`checked_usd` refuses (NaN, negative, a bool, a string) is
    **unknown**, not an error (nw#155): a host's own ``estimated_usd=`` raises
    because the host can fix it, but this one comes from a client, and raising
    would break clients that send junk today. Unknown requires approval, so
    junk loses the free pass instead of buying one (``nan >= threshold`` is
    ``False``), and it never reaches the job's ``cost``.
    """
    value = params.get("estimated_usd") if isinstance(params, Mapping) else None
    return _usable_usd(value, what="params['estimated_usd']")


def _usable_usd(value: Any, *, what: str) -> float | None:
    """:func:`checked_usd` for a figure nw takes from someone it cannot make
    fix it (a client, a render's event): a refused value is **unknown**
    (``None``) instead of an error. Warned once per ``what`` per process,
    later at debug level, because the same sender repeats it on every call.
    """
    try:
        return checked_usd(value, name=what)
    except ValueError as exc:
        level = logging.DEBUG if what in _warned_unusable_usd else logging.WARNING
        _warned_unusable_usd.add(what)
        _logger.log(level, "%s; treated as unknown", exc)
        return None


_warned_unusable_usd: set[str] = set()
"""The ``what`` names :func:`_usable_usd` has already warned about."""

def checked_usd(value: Any, *, name: str = "estimated_usd") -> float | None:
    """``value`` as a ``float`` if it is a price nw can gate on, else ``ValueError``.

    A ``float`` so that what is stored is JSON (a numpy scalar or a
    ``Fraction`` passes the check and would fail the index write).

    ``None`` (unknown) or a finite, non-negative real. A bool is refused (it is
    an ``int``), and so is NaN: ``nan >= threshold`` is ``False``, so a NaN
    price would pass every approval gate as cheap. So is an ``int`` too large
    for a ``float``, as ``ValueError`` rather than ``OverflowError``, so a
    caller that tolerates a bad price catches one exception type. ``name``
    is the figure the error message names.
    """
    if value is None:
        return None
    usd = math.nan  # refused unless it is a real nw can hold as a float
    if isinstance(value, numbers.Real) and not isinstance(value, bool):
        with suppress(OverflowError):  # an int too large for a float
            usd = float(value)
    if not math.isfinite(usd) or usd < 0:
        raise ValueError(
            f"{name} must be None or a finite, non-negative number, "
            f"got {type(value).__name__} {reprlib.repr(value)}"
        )
    return usd




def _estimate(
    params, *, quote: "PlanQuote | None" = None, host_usd: Any = _UNSET
) -> tuple[float | None, str | None]:
    """This job's price today and where it came from (``ESTIMATE_FROM_*``):
    the host's own figure when it gave one (``host_usd``, nw#144), else the
    re-quoted plan, else the caller's figure.

    ``None`` means unknown — never free, and never the stale number that came
    in with the plan. Pass ``quote`` to reuse one already computed for these
    same ``params``; it is re-derived when omitted. One function answers both,
    so the figure and its source cannot disagree.
    """
    if host_usd is not _UNSET:
        return host_usd, ESTIMATE_FROM_HOST
    quote = quote if quote is not None else _quote_params(params)
    if quote is not None:
        return quote.total_usd, ESTIMATE_FROM_PLAN
    caller = _caller_estimated_usd(params)
    return caller, (ESTIMATE_FROM_CALLER if caller is not None else None)

    "quoted; see the server log for what went wrong"
)
"""Why a quote came back unknown when the plan itself was unreadable.

A fixed sentence rather than the exception text: this string reaches a job
surface, and an exception's message is written for an operator reading a log,
not for whoever is deciding whether to approve a spend."""


def _quote_params(params) -> "PlanQuote | None":
    """Today's price for ``params["plan"]``, or ``None`` when no plan is given.

    ``None`` means "nw was handed no plan to quote", never "this is free" —
    the caller's own ``estimated_usd`` is the fallback, and it is a figure nw
    cannot vouch for.

    Accepts whatever :func:`_plan_for_identity` accepts — a live
    :class:`falaw.Plan` or the ``plan_to_dict`` dict a job's ``params`` can
    actually carry through the index. Anything else is *unknown*: this
    function never raises, because refusing to name a price is the safe answer
    at a cost gate, and :func:`_default_idempotency_key` is where an
    unidentifiable plan is refused loudly.
    """
    from .pricing import current_quote, unquotable

    plan = params.get("plan") if isinstance(params, Mapping) else None
    if plan is None:
        return None
    try:
        return current_quote(_plan_for_identity(plan))
    except Exception:  # noqa: BLE001 — an unreadable plan is *unknown*
        _logger.warning("could not read params['plan'] to re-quote it", exc_info=True)
        return unquotable(UNREADABLE_PLAN_REASON)

def list_jobs(
    project,
    *,
    status: str | None = None,
    limit: int = 50,
    config: JobsConfig = DEFAULT_CONFIG,
) -> list[Job]:
    """Jobs for this project, **newest first**, optionally filtered by status.

    Backed by the per-project active-jobs index (not by scanning the au store,
    whose missing-key-returns-PENDING gotcha makes membership meaningless).
    Runs that ended more than ``config.index_retention_s`` ago move to the
    archive during the scan and are not listed (:func:`_archive_old_runs`).
    """
    rt = _runtime(project, config)
    records = [r for r in (_index_snapshot(rt, k) for k in list(rt.index)) if r]
    records = _archive_old_runs(rt, records, config, project=project)
    records.sort(key=lambda r: r.get("created_at") or "", reverse=True)

    jobs: list[Job] = []
    for record in records:
        job = _read_job(rt, record, config, project=project)
        if status is None or job.status == status:
            jobs.append(job)
        if len(jobs) >= limit:
            break
    return jobs

def archive_finished_runs(project, *, config: JobsConfig = DEFAULT_CONFIG) -> list[str]:
    """Move every run that ended more than ``config.index_retention_s`` ago
    from the live index to the archive, now; return their ids (nw#174).

    The same move :func:`list_jobs` makes on its throttled scan, for a host to
    schedule off the request path, e.g. a big project's first sweep after an
    upgrade (seconds at 10k runs). With ``index_sweep_interval_s=None`` it is
    the only sweep: ``list_jobs`` then never writes to archive.

    An old run that is not over yet is settled first (:func:`_settle_straggler`):
    a run nobody announced is read, which reaps a dead worker and announces
    the end, and, only when ``never_started_after_s`` is set, a run queued
    that long with no worker anywhere is failed as never started. They then
    leave on a later sweep, so no record costs a lock on every sweep forever.
    Best-effort per run, like ``list_jobs``'s.
    """
    rt = _runtime(project, config)
    records = [r for r in (_index_snapshot(rt, k) for k in list(rt.index)) if r]
    return sorted(_sweep(rt, records, config, project=project))




def _archive_old_runs(rt, records, config, *, project) -> list:
    """``records`` minus the runs this call moved from the index to
    ``rt.archive`` (nw#169), at most once per ``index_sweep_interval_s`` per
    runtime, and never when that is ``None`` (the host sweeps, nw#174).

    The age is judged on the scan's snapshots, so a project with nothing old
    pays nothing beyond the scan it was doing anyway (:func:`_sweep`).
    """
    interval = config.index_sweep_interval_s
    if interval is None or time.monotonic() < rt.next_sweep:
        return records
    rt.next_sweep = time.monotonic() + interval
    moved = _sweep(rt, records, config, project=project)
    return [r for r in records if r["job_id"] not in moved] if moved else records


def _sweep(rt, records, config, *, project) -> set[str]:
    """Settle, then archive, each of ``records`` that ended before
    ``index_retention_s`` ago, and settle each run queued longer than
    ``never_started_after_s``; return the ids moved. Each candidate is
    re-read and moved under ``rt.lock`` (:func:`_archive_if_settled`)."""
    retention, patience = config.index_retention_s, config.never_started_after_s
    cutoff = _utcnow_plus(-retention) if retention is not None else None
    start_by = _utcnow_plus(-patience) if patience is not None else None
    moved = set()
    for record in records:
        old = cutoff is not None and _ended_before(record, cutoff)
        stuck = start_by is not None and _never_started_by(record, start_by)
        if old or stuck:
            _settle_straggler(rt, record, config, project=project, stuck=stuck)
        if old and _archive_quietly(rt, record["job_id"], cutoff, config):
            moved.add(record["job_id"])
    return moved


def _never_started_by(record, start_by: datetime) -> bool:
    """Whether ``record``'s run was created before ``start_by`` and has
    neither started nor ended."""
    created = _parse_iso(record.get("created_at"))
    return (
        record.get("started_at") is None
        and record.get("finished_at") is None
        and created is not None
        and created < start_by
    )


NEVER_STARTED_REASON = "never started — resumable"
"""A queued run older than ``never_started_after_s`` with no worker anywhere."""


def _settle_straggler(rt, record, config, *, project, stuck: bool) -> None:
    """Bring an old run that is not over to an end it can be archived from
    (nw#174), best-effort. A ``stuck`` run (queued past
    ``never_started_after_s``) is failed as :data:`NEVER_STARTED_REASON`
    when nothing is alive behind it. Then a run nobody announced (one past
    every ``list_jobs`` limit, so nothing read it) is read, which reaps a dead
    running worker and announces a terminal run
    (:func:`register_terminal_hook`)."""
    try:
        if stuck:
            _fail_never_started(rt, record, config)
        if record.get("terminal_announced") is False:
            _read_job(rt, record, config, project=project)
    except Exception:  # noqa: BLE001 — housekeeping never fails the caller
        _logger.warning("could not settle old job %s", record["job_id"], exc_info=True)


def _fail_never_started(rt, record, config) -> None:
    """Fail ``record``'s queued run, deciding under ``rt.lock`` on a fresh read
    as the reaper does (:func:`_maybe_reap`): the same run, still never
    started (no ``started_at`` / ``finished_at``, au PENDING, which is also
    what a missing au entry reads as), no worker alive here or beating
    anywhere."""
    job_id = record["job_id"]
    with rt.lock:
        fresh = _index_get_locked(rt, job_id)
        if (
            fresh is None
            or fresh.get("run_token") != record.get("run_token")
            or fresh.get("started_at") is not None
            or fresh.get("finished_at") is not None
            or rt.middleware.is_running_locked(job_id)
            or _heartbeat_is_fresh(fresh, config)
            or rt.au_store[job_id].status is not ComputationStatus.PENDING
        ):
            return
        _fail_locked(rt, job_id, NEVER_STARTED_REASON)


def _archive_quietly(rt, job_id, cutoff: datetime, config) -> bool:
    """:func:`_archive_if_settled`, best-effort: archiving is housekeeping on
    a read path, so a failure (a full disk, a refused unlink) is logged and the
    run stays live, never failing the poll."""
    try:
        return _archive_if_settled(rt, job_id, cutoff, config)
    except Exception:  # noqa: BLE001 — the poll matters more than the sweep
        _logger.warning(
            "could not archive job %s; it stays in the index", job_id, exc_info=True
        )
        return False


def _ended_before(record, cutoff: datetime) -> bool:
    """Whether ``record``'s run ended (or, lacking an end, was created) before
    ``cutoff``."""
    ended = _parse_iso(record.get("finished_at") or record.get("created_at"))
    return ended is not None and ended < cutoff


def _archive_if_settled(rt, job_id, cutoff: datetime, config) -> bool:
    """Move ``job_id``'s record to the archive if its run is over for good:
    still old on a fresh read, au terminal, announced (or from before
    announcing), not under an announcement lease, and with no worker alive
    here or beating anywhere. Returns whether it moved."""
    with rt.lock:
        record = _index_get_locked(rt, job_id)
        if (
            record is None
            or not _ended_before(record, cutoff)
            or record.get("terminal_announced") is False
            or _lease_is_live(record.get("announce_claim"))
            or rt.middleware.is_running_locked(job_id)
            or _heartbeat_is_fresh(record, config)
            or rt.au_store[job_id].status not in _AU_TERMINAL
        ):
            return False
        rt.archive[job_id] = record  # archive first: a crash between keeps both
        del rt.index[job_id]
    return True

def summarize(
    project_root, *, limit: int = 50, config: JobsConfig = DEFAULT_CONFIG
) -> list[Job]:
    """This project's jobs **without provisioning it**. Newest first.

    :func:`list_jobs` looks like a read and is not. It calls :func:`_runtime`,
    which creates ``.nw/jobs/{au,index,durations}`` and memoizes a
    :class:`_JobsRuntime` — *which owns a render ``ThreadBackend``* — into the
    unbounded module-global ``_RUNTIMES``. Measured on a never-rendered
    project::

        before: .nw/jobs exists? False   _RUNTIMES size: 0
        list_jobs(project)  ->  0 rows
        after : .nw/jobs exists? True ['au', 'durations', 'index']
                _RUNTIMES size: 1, runtime owns a ThreadBackend

    A cross-project dashboard polling N projects is exactly the caller that
    turns that into render machinery for every project a user has ever glanced
    at, held for the life of the process. So this reads what is there and
    creates nothing: **no directory, no backend, no ``_RUNTIMES`` entry**, and
    ``[]`` for a project that has never run a job.

    It also performs neither write :func:`_read_job` does:

    - **No reaping.** Marking someone else's job failed is a write, and a
      read-only fan-out across projects has no business doing it. A job that
      needs reaping will be reaped by a caller that is actually looking at it.
    - **No ``pct_floor`` persistence.** The monotonic floor is a write too.
      Progress may therefore appear to tick backwards *within this view* if a
      prediction lengthens; that is the honest cost of not writing, and the
      per-project view still holds the floor.

    Status still comes from the au store, never from the index record's own
    ``status`` field: ``FileSystemStore`` synthesizes ``PENDING`` for a missing
    key, so membership lives in the index while *outcome* lives in the store,
    and trusting the index's copy reports finished jobs as queued.
    """
    base = Path(project_root) / config.jobs_dirname
    index_dir, au_dir = base / "index", base / "au"
    if not index_dir.is_dir() or not au_dir.is_dir():
        return []

    index = AtomicJsonFiles(index_dir)
    au_store = FileSystemStore(str(au_dir), ttl_seconds=None)
    records = [r for r in (index.get(k) for k in list(index)) if r]
    records.sort(key=lambda r: r.get("created_at") or "", reverse=True)

    # A stand-in for the runtime, carrying only what the pure projection
    # touches. Deliberately not a real ``_JobsRuntime``: building one is the
    # provisioning this function exists to avoid.
    rt = _ReadOnlyRuntime(index=index, au_store=au_store, durations=_EMPTY_DURATIONS)

    jobs: list[Job] = []
    for record in records[:limit]:
        try:
            au_result = au_store[record["job_id"]]
        except Exception:  # noqa: BLE001 — one unreadable job must not hide the rest
            continue
        jobs.append(_project_job(rt, record, au_result, config))
    return jobs

    the backend or the middleware. ``durations`` is empty rather than the real
    learner: reading it would be harmless, but opening it creates the directory
    this function promises not to create.
    """

    index: MutableMapping
    au_store: FileSystemStore
    durations: Mapping

def get_job(project, job_id: str, *, config: JobsConfig = DEFAULT_CONFIG) -> Job | None:
    """One job (projecting the au status + mirrored index metadata). ``None`` if
    unknown. Reaps a stale-RUNNING record on read. Answers for an archived run
    too (nw#169): a finished, announced run, so the read writes nothing."""
    rt = _runtime(project, config)
    # Index, archive, index: a re-run's enqueue writes the index before it
    # drops the archived copy, so a read that missed both meanwhile finds
    # the new run on the third look rather than calling a live job unknown.
    record = (
        _index_snapshot(rt, job_id)

def cancel_job(
    project, job_id: str, *, config: JobsConfig = DEFAULT_CONFIG
) -> Job | None:
    """Request cancellation. **Idempotent.** ``None`` if unknown.

    Sets a durable should-cancel flag (a running stage stops at its next
    boundary) *and* flips the au record terminal at once via ``au.cancel_task``
    (which builds the handle **with the backend** so ``terminate`` is reached).
    The ``cancel_requested`` flag is authoritative, so the job reads
    ``cancelling`` → ``cancelled`` even if the still-running thread later
    overwrites the store with COMPLETED.

    **A job that has already finished is not cancelled — the call is a no-op**
    and returns the job unchanged. Because the flag is authoritative for
    status, setting it on a terminal record rewrote a SUCCEEDED job to
    ``cancelled`` and dropped its ``result`` and ``pct`` (and a FAILED job's
    ``error``): work that ran, finished and *billed*, reported as though it had
    not. Cancelling is a request about the future, and there is no future left
    to change.
    """
    rt = _runtime(project, config)
    with rt.lock:
        record = _index_get_locked(rt, job_id)
        # A cancel that arrives after the work finished is a NO-OP, not a
        # rewrite. ``cancel_requested`` is authoritative for status, so setting
        # it unconditionally turned an already-SUCCEEDED job into ``cancelled``
        # with ``result`` and ``pct`` dropped — a finished, already-BILLED unit
        # of work reported as if it had never happened. The window is the poll
        # gap, and a long render behind a prominent "stop" button is exactly the
        # shape that produces a late click.
        #
        # Read the au record, not the index: the index carries intent, the au
        # store carries outcome. The index read-modify-write is excluded across
        # replicas by ``rt.lock`` (nw#148), but au writes its outcome outside
        # that lock, so a worker finishing between this read and the write
        # below can still race it; the window is two statements, not the poll
        # gap. A record absent from the index is archived (finished, so this is
        # the same no-op, nw#169) or unknown: ``get_job`` below answers both.
        if record is None:
            already_finished = True
        else:
            already_finished = (
                _normalize_status(
                    rt.au_store[job_id].status,
                    cancel_requested=bool(record.get("cancel_requested")),
                )
                in TERMINAL_STATUSES
            )
        if not already_finished:
            record["cancel_requested"] = True
            _index_set_locked(rt, job_id, record)
    if already_finished:
        # Outside the lock: ``get_job`` -> ``_maybe_reap`` takes it, and
        # ``threading.Lock`` is not reentrant.
        return get_job(project, job_id, config=config)
    # Flip the durable record terminal immediately (idempotent: no-op if already
    # terminal). Passing the backend lets cancel() reach terminate() (§3.1).
    au.cancel_task(job_id, backend=rt.backend, store=rt.au_store)
    rt.notifier.notify()
    return get_job(project, job_id, config=config)

class DurationLearningMiddleware(Middleware):
    """Keyed, percentile duration learner — a cousin of ``au.MetricsMiddleware``.

    Records the render wall-time under the job's ETA-key candidates, so a cold
    specific key backs off to a warmer coarse one. The specific ``learned``
    keys get the whole-job sample. The coarse ``output_kind`` key is **shared
    across operations** and means *seconds per unit*, so a job that has
    specific keys writes it only when it declared ``params["units"]``, and
    then with ``elapsed / units``. Such a job of unknown multiplicity never
    touches the shared bucket: forgetting ``units`` costs a cold coarse
    bucket, never a corrupted one (nw#67 — a 4-render job used to write its
    4-fold duration into the ``image`` bucket single-image jobs read from).
    A job whose *only* key is the coarse one (no model/operation) keeps
    learning in it as before — it has nowhere else to learn. Such a job that
    really covers N units should still declare ``units``, or it writes its
    N-fold duration into the shared bucket, exactly as before nw#67. Two deliberate departures
    from ``au``'s built-in metrics:

    - **Self-timed** (``time.monotonic`` in ``before_compute`` → ``after_compute``)
      rather than reading ``result.duration``: ``ThreadBackend`` constructs a
      *fresh* COMPLETED ``ComputationResult`` whose ``created_at`` is the
      completion instant, so ``result.duration`` is ~0 and useless. (Surfaced
      as an ``au`` finding.)
    - **Cache-hits are never learned** — a ~0s cache hit would drag the median
      to zero. The job's ``cached`` flag (mirrored from a ``cache_hit`` event
      during the run) gates recording.

    Its ``_start`` map doubles as the in-process **liveness signal** the stale
    reaper uses (a RUNNING au record whose key is not in ``_start`` and whose
    ``started_at`` is old is a dead worker).
    """

    def __init__(
        self,
        *,
        durations: MutableMapping,
        index: MutableMapping,
        lock: AbstractContextManager[Any],
        config: JobsConfig = DEFAULT_CONFIG,
    ):
        self._durations = durations
        self._index = index
        self._lock = lock
        self._config = config
        self._start: dict[str, float] = {}
        self._tokens: dict[str, str] = {}  # key -> run_token, from claim to end

    def before_compute(
        self, func: Callable, args: tuple, kwargs: dict, key: str
    ) -> None:
        # This hook is the running-transition boundary: the ThreadBackend worker
        # runs it *before* it writes the RUNNING record (base.py: middleware-before
        # → store[key]=RUNNING → func()). Stamping ``started_at`` here — in the
        # same lock as the liveness map — guarantees a job can never be observed
        # as ``running`` with ``started_at is None`` (closes a CI race where a slow
        # runner polled the window between the RUNNING write and a later stamp).
        with self._lock:
            self._start[key] = time.monotonic()
            record = self._index.get(key)
            if record is not None and record.get("started_at") is None:
                record["started_at"] = now_iso()
                self._index[key] = record





[docs]
    def after_compute(self, key: str, result: ComputationResult) -> None:
        now = time.monotonic()
        # One critical section: popping ``_start`` frees the key for a re-enqueue,
        # and a gap before the index read let the old run learn from the NEW
        # record's ETA keys / units / cached flag (nw#128).
        with self._lock:
            try:
                start = self._start.pop(key, None)
                if start is None:
                    return
                elapsed = now - start
                record = self._index.get(key)
                if not record or record.get("cached"):
                    return  # cache-hit (or unknown) → do NOT learn
                if record.get("run_token") != self._tokens.get(key):
                    # Another replica relaunched the key once au had this run's
                    # outcome: the record is the new run's, not this one's (nw#149).
                    return
                candidates = [tuple(c[:2]) for c in record.get("eta_candidates") or []]
                units = record.get("units")
                has_own_key = any(conf != _COARSE for _, conf in candidates)
                for eta_key, confidence in candidates:
                    if confidence != _COARSE:
                        self._record_sample_locked(eta_key, elapsed)
                    elif units is not None:
                        self._record_sample_locked(eta_key, elapsed / units)
                    elif not has_own_key:
                        # The coarse key is this job's only key (no model/operation,
                        # e.g. an explicit ``output_kind="compute"``): it is the
                        # job's own history, as it always was.
                        self._record_sample_locked(eta_key, elapsed)
                    # else: unknown multiplicity and an own key to learn in —
                    # never write the shared per-unit bucket (nw#67).
            finally:
                # Same section: the key is freed and its run marked exited
                # together, after au's terminal write (nw#149).
                self._mark_exit_locked(key)

        with self._lock:
            self._mark_exit_locked(key)
            self._start.pop(key, None)

    def claim_locked(self, key: str, *, run_token: str) -> None:
        """Mark ``key`` live before its worker thread has started (caller holds
        the lock). ``before_compute`` re-stamps the time; ``after_compute`` /
        ``on_error`` release it, :meth:`release_locked` undoes it if the launch
        itself fails. Without it a cancel plus a re-enqueue inside the window
        before the thread registers launched a second worker (nw#128).

        ``run_token`` is the run whose ``worker_exited_at`` the end hooks stamp:
        they run after au's terminal write, so a cancelled key is not freed for
        another replica before the old run's outcome has landed (nw#149)."""
        self._start[key] = time.monotonic()
        self._tokens[key] = run_token

    def release_locked(self, key: str) -> None:
        """Undo :meth:`claim_locked` when the launch itself failed."""
        self._start.pop(key, None)
        self._tokens.pop(key, None)



    def _mark_exit_locked(self, key: str) -> None:
        if key not in self._tokens:
            return
        try:
            _mark_worker_exited_locked(self._index, key, self._tokens.pop(key))
        except Exception:  # noqa: BLE001 — reporting must not break the worker
            pass

    def is_running(self, key: str) -> bool:
        with self._lock:
            return self.is_running_locked(key)

        """:meth:`is_running` for a caller already holding the runtime lock
        (it is this middleware's lock too, and not reentrant)."""
        return key in self._start

def predict_total_s(
    eta_candidates: list,
    output_kind: str | None,
    *,
    durations: MutableMapping,
    expected_cache_hit: bool = False,
    units: int | None = None,
    config: JobsConfig = DEFAULT_CONFIG,
) -> _Prediction:
    """Predict the total render seconds for a job as ``(p50, p90, confidence)``.

    Walks the ETA-key candidates most-specific-first; the first key with
    ``>= n_min`` samples wins (median, with a real or synthesized p90). Falls
    back through the coarse key, the output-kind key, then the cold prior. An
    all-cache-hit plan short-circuits to ``cache_hit_floor_s`` (``"exact"``).

    ``units`` scales the per-unit answers — a ``learned_coarse`` hit and the
    cold prior — to the job; a specific ``learned`` key already holds
    whole-job samples and is returned as is. ``None`` means one.
    """
    scale = units or 1
    if expected_cache_hit:
        return _Prediction(config.cache_hit_floor_s, config.cache_hit_floor_s, "exact")
    for cand in eta_candidates:
        key, conf = cand[0], cand[1]
        samples = _durations_get(durations, key)
        if len(samples) >= config.n_min:
            p50 = statistics.median(samples)
            p90 = _percentile(samples, 90)
            if p90 is None or p90 < p50:
                p90 = p50 * config.overrun_factor
            if conf == _COARSE:
                p50, p90 = p50 * scale, p90 * scale
            return _Prediction(p50, p90, conf)
    prior = scale * config.prior_total_s.get(output_kind, config.default_prior_total_s)
    return _Prediction(prior, prior * config.overrun_factor, "prior")

def _finite_json(value: Any) -> Any:
    """``value`` with every non-finite float (NaN, ±inf) replaced by ``None``.

    JSON has no such numbers: Python's ``json`` writes a bare ``NaN`` token
    that strict parsers (a browser's ``JSON.parse``) reject, so one NaN in a
    client's ``params`` or a render's progress made the job unservable
    (nw#166). Mappings and sequences are walked; anything else is returned
    as is (tuples come back as lists, as JSON would make them).

    >>> _finite_json({"a": float("nan"), "b": [1.5, float("inf")], "c": "x"})
    {'a': None, 'b': [1.5, None], 'c': 'x'}
    """
    if isinstance(value, float):
        return value if math.isfinite(value) else None
    if isinstance(value, Mapping):
        return {k: _finite_json(v) for k, v in value.items()}
    if isinstance(value, (list, tuple)):
        return [_finite_json(v) for v in value]
    return value

    (PermissionError,) if os.name == "nt" else ()

class AtomicJsonFiles(MutableMapping):
    """A ``{key: json-value}`` directory store whose writes are **atomic**.

    Drop-in for the ``dol.JsonFiles`` it replaced — same on-disk layout, one
    plain-named file per key holding JSON — with the one difference this
    module needs (reelee#298): ``__setitem__`` serializes fully in memory,
    writes to a sibling temp file, and ``os.replace``\\ s it over the
    destination. ``os.replace`` is atomic on POSIX and Windows, so a
    concurrent reader observes either the old record or the new one — never
    a truncated or empty file.

    Why here: the job index is rewritten by the worker thread on every
    mirrored event (and even on reads, for the pct floor) while reelee's API
    polls ``get_job`` concurrently. With a truncate-then-write store, a read
    can land in the window after ``open(..., "w")`` and before the bytes —
    ``json.loads("")`` — surfacing as an intermittent 500 precisely during a
    cancel, when clients poll hardest. The au store already writes this way;
    now every durable record this module owns does too.

    A failed serialization touches nothing: the old record survives and no
    temp file is left behind. Temp names start with ``.`` so iteration never
    lists an in-flight write as a key.

    Readers need no lock, on Windows too (nw#170): there a reader holding the
    file open makes ``os.replace`` / ``os.unlink`` of it fail with
    ``PermissionError`` until it closes, so a write retries those briefly
    (``retry_on``, ``attempts``, doubling from ``backoff_s``: ~0.6 s in all by
    default). A read is milliseconds; the retries outlast it, and they cost
    nothing unless a write is actually refused.
    """

    def __init__(
        self,
        rootdir: str | Path,
        *,
        retry_on: tuple[type[BaseException], ...] | None = None,
        attempts: int = 7,
        backoff_s: float = 0.01,
    ) -> None:
        self._rootdir = Path(rootdir)
        self._rootdir.mkdir(parents=True, exist_ok=True)
        self._retry_on = _SHARING_VIOLATIONS if retry_on is None else retry_on
        self._attempts = attempts
        self._backoff_s = backoff_s

    def _retrying(self, op, *args):
        """``op(*args)``, retried on ``self._retry_on`` with doubling backoff."""
        for attempt in range(self._attempts):
            try:
                return op(*args)
            except self._retry_on:
                if attempt == self._attempts - 1:
                    raise
                time.sleep(self._backoff_s * 2**attempt)

    def _path(self, key: str) -> Path:
        # Keys here are filesystem-safe by construction (sha256 hex job ids,
        # percent-encoded ETA keys); refuse anything that could escape the
        # directory rather than silently writing elsewhere.
        if not key or key != Path(key).name or key.startswith("."):
            raise ValueError(f"not a safe store key: {key!r}")
        return self._rootdir / key

    def __getitem__(self, key: str):
        try:
            text = self._path(key).read_text(encoding="utf-8")
        except FileNotFoundError:
            raise KeyError(key) from None
        return json.loads(text)

    def __setitem__(self, key: str, value) -> None:
        path = self._path(key)
        try:  # serialize BEFORE touching disk
            data = json.dumps(value, allow_nan=False)
        except ValueError:  # NaN/inf: JSON has none, so store them as null
            data = json.dumps(_finite_json(value), allow_nan=False)
        data = data.encode("utf-8")
        fd, tmp = tempfile.mkstemp(dir=self._rootdir, prefix=f".{key}.", suffix=".tmp")
        try:
            with os.fdopen(fd, "wb") as f:
                f.write(data)
        except BaseException:
            with suppress(OSError):  # best-effort cleanup; the raise is the point
                os.unlink(tmp)
            raise
        try:
            self._retrying(os.replace, tmp, path)
        except BaseException:
            with suppress(OSError):  # no orphaned temp file when the swap fails
                os.unlink(tmp)
            raise

    def __delitem__(self, key: str) -> None:
        try:
            self._retrying(os.unlink, self._path(key))
        except FileNotFoundError:
            raise KeyError(key) from None

    def __iter__(self) -> Iterator[str]:
        return (
            p.name
            for p in self._rootdir.iterdir()
            if p.is_file() and not p.name.startswith(".")
        )

    def __len__(self) -> int:
        return sum(1 for _ in self)

    def __contains__(self, key) -> bool:
        try:
            return self._path(key).is_file()
        except ValueError:
            return False

class JobNotifier:
    """A change counter with a wakeup: "some job of this project changed state".

    One per project runtime, so a change in one project never wakes another's
    waiters. Waiters read :meth:`count` BEFORE inspecting jobs and hand it to
    :meth:`wait`, so a change landing in between is not lost. The wakeup is a
    *hint*: reaping and other processes' workers change jobs without calling
    :meth:`notify`, so a waiter bounds its timeout and re-reads.
    """

    def __init__(self) -> None:
        self._cond = threading.Condition()
        self._count = 0

    def notify(self) -> None:
        with self._cond:
            self._count += 1
            self._cond.notify_all()

    def count(self) -> int:
        with self._cond:
            return self._count



[docs]
    def wait(self, seen: int, timeout: float) -> None:
        """Block until the counter moves past ``seen`` or ``timeout`` seconds pass."""
        with self._cond:
            self._cond.wait_for(lambda: self._count != seen, timeout=timeout)

def register_terminal_hook(
    name: str, hook: Callable[[Any, Job], None]
) -> Callable[[Any, Job], None]:
    """Call ``hook(project, job)`` when a job's run ends (nw#151).

    "Ends" is the first time the run is read terminal — succeeded, failed or
    cancelled — wherever that happens: the managed backend's worker as it
    finishes, :func:`cancel_job`, the stale-worker reaper, any :func:`get_job` /
    :func:`list_jobs`, or :func:`enqueue` about to replace a finished run nobody
    read. A re-run of the key is a new run and is announced again.

    - **Every project.** Hooks are process-wide: they fire for every project nw
      runs jobs in, a guest genre's included, so a hook filters on ``project``.
    - **Cancelled as of the announcement.** A cancelled job is announced at
      once, while its worker may still be running (cancel is cooperative) and
      may still add cost.
    - **On the reading thread**, outside nw's locks (a hook may call back into
      ``nw.jobs``). Inside :func:`list_jobs` it adds to that poll's latency.
    - **At least once, per hook.** A hook that raises is logged, never
      propagated, and called again on a later read, up to
      ``JobsConfig.terminal_hook_attempts`` announcements of that run; the hooks
      that already returned are not called again. The exception is
      :func:`enqueue` replacing a finished run: that run's record is gone, so a
      hook failing there is not retried.
    - **Once, across replicas** sharing a jobs root on a lockable filesystem:
      the claim is a lease written on the run's record under the index lock
      (``JobsConfig.terminal_hook_lease_s``), so a run is announced by one
      thread of one replica at a time. A host still dedupes, on
      ``(job.job_id, job.run_token)`` since a re-run shares the ``job_id``, for
      the two cases that defeat it: a claimant that dies after a hook returned
      but before recording it (the run is re-announced once its lease
      expires), and a filesystem that refuses locks (nw logs a warning).

    Runs recorded before this existed are never announced. Remove one with
    ``del terminal_hooks[name]``.
    """
    if not callable(hook):
        raise TypeError(f"terminal hook {name!r} must be callable")
    terminal_hooks.register(name, hook)
    return hook




def _claim_announcement_locked(rt, record, *, run_token) -> str | None:
    """Claim the announcement of run ``run_token`` (caller holds ``rt.lock``);
    return the claim's id, or ``None`` when it is not this caller's to make.

    Only a run that is still ``record``'s, not yet announced (an absent flag is
    a record from before announcing) and not under another live claim is
    claimed. The claim is a lease stamped on ``record`` and written to the
    index, so it excludes other replicas and this one's threads alike;
    :func:`_fire_terminal_hooks` releases it. The id is per claim, not per
    runtime, so a thread whose lease expired cannot release the one that took
    it over, even in the same process."""
    if _announcement_settled(record, run_token) or _lease_is_live(
        record.get("announce_claim")
    ):
        return None
    claim = uuid4().hex
    until = _iso(_utcnow_plus(rt.config.terminal_hook_lease_s))
    record["announce_claim"] = {"by": claim, "until": until}
    _index_set_locked(rt, record["job_id"], record)
    return claim


def _announcement_settled(record, run_token) -> bool:
    """Whether run ``run_token`` can no longer be announced from ``record``:
    the record is gone, holds another run, was announced, or predates
    announcing. Each only ever moves one way for a run, so a lock-free
    snapshot that says "settled" stays right (nw#158)."""
    return (
        record is None
        or record.get("run_token") != run_token
        or record.get("terminal_announced") is not False
    )


def _lease_is_live(claim) -> bool:
    """Whether ``claim`` (an ``announce_claim``) has not expired; an unreadable
    one reads expired, so a corrupt lease cannot hold a run forever."""
    until = _parse_iso(claim.get("until")) if isinstance(claim, Mapping) else None
    return until is not None and until > _utcnow()


def _holds_lease(record, claim) -> bool:
    lease = record.get("announce_claim")
    return isinstance(lease, Mapping) and lease.get("by") == claim


def _fire_terminal_hooks(rt, project, job: Job, *, run_token, claim) -> None:
    """Run the hooks a claimed run has not yet been announced to, record which
    returned, and mark the run announced once none is left owing (or the failing
    ones are out of attempts); release the lease on every path, so what failed
    is retried by the next read. A lease taken over after it expired is the new
    claimant's: this one then records nothing."""
    try:
        with rt.lock:
            record = _this_run_locked(rt, job.job_id, run_token) or {}
        done = set(record.get("announced_to") or ())
        failed = []
        for name, hook in list(terminal_hooks.items()):
            if name in done:
                continue
            try:
                hook(project, job)
                done.add(name)
            except Exception:  # noqa: BLE001 — a host's hook must not break a read
                failed.append(name)
                _logger.exception(
                    "nw.jobs: terminal hook %r failed for %s", name, job.job_id
                )
        with rt.lock:
            record = _this_run_locked(rt, job.job_id, run_token)
            if record is None or not _holds_lease(record, claim):
                return
            attempts = record.get("announce_attempts", 0) + 1
            given_up = bool(failed) and attempts >= rt.config.terminal_hook_attempts
            if given_up:
                _logger.warning(
                    "nw.jobs: giving up on terminal hooks %s for %s after %d attempts",
                    failed,
                    job.job_id,
                    attempts,
                )
            del record["announce_claim"]
            record.update(
                announced_to=sorted(done),
                announce_attempts=attempts,
                terminal_announced=not failed or given_up,
            )
            _index_set_locked(rt, job.job_id, record)
    finally:
        with rt.lock:
            record = _this_run_locked(rt, job.job_id, run_token)
            if record is not None and _holds_lease(record, claim):
                del record["announce_claim"]
                _index_set_locked(rt, job.job_id, record)


def _this_run_locked(rt, job_id, run_token):
    """``job_id``'s record if it is still run ``run_token``'s, else ``None``."""
    record = _index_get_locked(rt, job_id)
    return (
        record if record is not None and record.get("run_token") == run_token else None
    )


def _announce_if_terminal(rt, project, job: Job, *, run_token) -> None:
    """Announce ``job`` if it reads terminal and run ``run_token`` — the run the
    read started from — is still the key's current, unannounced run."""
    if job.status not in TERMINAL_STATUSES or _announcement_settled(
        _index_snapshot(rt, job.job_id), run_token
    ):
        return  # without the lock: most terminal reads are of announced runs
    with rt.lock:
        claim = _claim_announcement_locked(
            rt, _index_get_locked(rt, job.job_id), run_token=run_token
        )
    if claim is not None:
        _fire_terminal_hooks(rt, project, job, run_token=run_token, claim=claim)


class _AnnounceMiddleware(Middleware):
    """Announces a managed-backend job's end from its worker (nw#151).

    Placed after :class:`_NotifyMiddleware`. :func:`enqueue` records the
    enqueuing project per key at launch (:meth:`launch_locked`, under the lock,
    alongside the liveness claim); at the end this reads the job through
    :func:`_read_job` on its own runtime, with that project, then forgets it — so
    a hook gets the caller's project and nothing is pinned past the run. Entries
    are per-key FIFO: a re-enqueue can land between the old worker's liveness
    release and this read, and must not take the old run's entry.
    """

    def __init__(self) -> None:
        self.runtime: _JobsRuntime | None = None  # bound once by :func:`_runtime`
        self._projects: dict[str, list] = {}

    def launch_locked(self, key: str, project) -> None:
        self._projects.setdefault(key, []).append(project)

    def release_locked(self, key: str) -> None:
        """Undo :meth:`launch_locked` when the launch itself failed."""
        self._pop_locked(key, index=-1)

    def before_compute(self, func, args, kwargs, key) -> None:
        pass

    def after_compute(self, key, result) -> None:
        self._end(key)

    def on_error(self, key, error) -> None:
        self._end(key)

    def _pop_locked(self, key: str, *, index: int) -> None:
        queue = self._projects.get(key)
        if queue:
            queue.pop(index)
        if not queue:
            self._projects.pop(key, None)

    def _end(self, key) -> None:
        rt = self.runtime
        with rt.lock:
            queue = self._projects.get(key)
            if not queue:
                return
            project = queue[0]
            record = _index_get_locked(rt, key)
        try:
            if record is not None:
                _read_job(rt, record, rt.config, project=project)
        except Exception:  # noqa: BLE001 — a read must not fail the worker
            _logger.exception("nw.jobs: end-of-job read failed for %s", key)
        finally:
            with rt.lock:
                self._pop_locked(key, index=0)

@dataclass
class _JobsRuntime:
    root: str
    au_store: FileSystemStore
    index: MutableMapping
    archive: MutableMapping
    durations: MutableMapping
    backend: ThreadBackend
    middleware: DurationLearningMiddleware
    lock: FileLock
    config: JobsConfig
    notifier: JobNotifier
    announcer: _AnnounceMiddleware
    next_sweep: float = 0.0
    """``time.monotonic()`` before which :func:`list_jobs` skips archiving."""


_RUNTIMES: dict[str, _JobsRuntime] = {}
_RUNTIMES_LOCK = threading.Lock()


def _runtime(project, config: JobsConfig = DEFAULT_CONFIG) -> _JobsRuntime:
    """Get-or-build the memoized job runtime for ``project`` (keyed by root).

    The first touch of a project fixes its runtime (stores + backend +
    middleware share one lock and one liveness map). ``config`` is honored on
    that first build.
    """
    root = str(Path(project.root).resolve())
    built = False
    with _RUNTIMES_LOCK:
        rt = _RUNTIMES.get(root)
        if rt is None:
            built = True
            base = Path(project.root) / config.jobs_dirname
            (base / "au").mkdir(parents=True, exist_ok=True)
            (base / "index").mkdir(parents=True, exist_ok=True)
            (base / "durations").mkdir(parents=True, exist_ok=True)
            au_store = FileSystemStore(str(base / "au"), ttl_seconds=None)
            # Atomic on purpose (reelee#298): these two are rewritten by the
            # worker while the API reads them; see :class:`AtomicJsonFiles`.
            index = AtomicJsonFiles(base / "index")
            durations = AtomicJsonFiles(base / "durations")
            archive = AtomicJsonFiles(base / "index-archive")  # nw#169
            # Cross-process (nw#148): every read-modify-write of the index and
            # the durations runs under this lock, so replicas sharing the jobs
            # root exclude each other exactly as threads do. ``dol``'s
            # ``FileLock`` is a ``threading.Lock`` that also holds an advisory
            # lock on ``index.lock`` beside the stores; where the filesystem
            # refuses locks it degrades to the thread lock (``lock.held``),
            # which :func:`_warn_if_lock_not_held` reports. One open handle per
            # memoized runtime. On NFS, ``flock`` is emulated with POSIX locks,
            # which belong to the process: two runtimes in one process there do
            # not exclude each other (separate processes still do).
            lock = FileLock(base / "index")
            middleware = DurationLearningMiddleware(
                durations=durations, index=index, lock=lock, config=config
            )
            notifier = JobNotifier()
            announcer = _AnnounceMiddleware()
            backend = ThreadBackend(
                store=au_store,
                middleware=[middleware, _NotifyMiddleware(notifier), announcer],
            )
            rt = _JobsRuntime(
                root=root,
                au_store=au_store,
                index=index,
                archive=archive,
                durations=durations,
                backend=backend,
                middleware=middleware,
                lock=lock,
                config=config,
                notifier=notifier,
                announcer=announcer,
            )
            announcer.runtime = rt
            _RUNTIMES[root] = rt
    if built:
        _warn_if_lock_not_held(rt)
    return rt


def _warn_if_lock_not_held(rt) -> None:
    """Warn, once per runtime, when the filesystem under the jobs root refuses
    the index lock (shared mounts such as SMB, some FUSE, Lustre): the body
    still runs under the thread lock, so replicas then lose each other's
    updates and may announce a run twice."""
    with rt.lock:
        held = rt.lock.held
    if not held:
        _logger.warning(
            "nw.jobs: the filesystem refuses the index lock %s; replicas sharing "
            "this jobs root do not exclude each other",
            rt.lock.path,
        )

def _bind_worker(
    project,
    kind,
    params,
    callable_,
    *,
    job_id,
    on_event,
    rt,
    config,
    extra_ctx=None,
    secrets=None,
    run_token,
    mark_exit=True,
):
    """Bind the render callable into a zero-arg worker body that (a) re-establishes
    request context (fal credentials + project + any caller-supplied context), (b)
    routes events into both the caller's sink and the index mirror, (c) exposes a
    durable ``should_cancel``.

    ``extra_ctx`` is the context manager :func:`enqueue` got from the caller's
    ``capture_context`` hook (called on the request thread); it is entered
    around the render on the worker thread (``ThreadBackend`` does not copy
    ``ContextVars`` into the worker, so anything the caller owns must be
    re-bound explicitly).

    ``run_token`` is the token :func:`enqueue` wrote on this run's record: the
    heartbeat and the exit marker touch the record only while it still carries
    it, so a stale worker never stamps a run that replaced its own. With
    ``mark_exit`` the worker writes the exit marker itself, as it leaves; the
    managed backend passes ``False`` and marks it from its middleware instead,
    after au's terminal write (nw#149)."""
    captured_fal_key = _capture_fal_credentials()

    def should_cancel() -> bool:
        record = _index_snapshot(rt, job_id)
        if record and record.get("cancel_requested"):
            return True
        try:
            return rt.au_store[job_id].status is ComputationStatus.CANCELLED
        except Exception:
            return False

    def sink(ev) -> None:
        _stamp_correlation(ev, job_id)
        try:
            if on_event is not None:
                on_event(ev)
        finally:
            try:
                _mirror_event_into_index(rt, job_id, ev)
            except Exception:
                pass

    def run():
        try:
            return _run()
        except Exception:
            raise
        except BaseException as e:
            # au's worker catches only ``Exception``: anything else would leave
            # the record RUNNING and ``_start`` set, so the key could never be
            # re-enqueued or reaped. Re-raised as an ordinary failure, from ANY
            # step of the run (the render, a context hook, the heartbeat
            # start, the terminal reconcile), with the redacted text (nw#128).
            raise JobAborted(
                f"{type(e).__name__}: {redact_exception(e, secrets)}"
            ) from None
        finally:
            # After ``_run`` has joined the beat, so no stamp lands after it.
            if mark_exit:
                _mark_worker_exited(rt, job_id, run_token)

    def _run():
        # ``started_at`` is stamped by the backend's ``before_compute`` hook, which
        # runs before the RUNNING transition is observable — see
        # :meth:`DurationLearningMiddleware.before_compute`. Nothing to stamp here.
        def call():
            return _call_dispatch(
                callable_,
                project,
                params,
                job_id=job_id,
                on_event=sink,
                should_cancel=should_cancel,
                secrets=secrets,
            )

        # Re-establish both credential contexts on the worker thread: fal
        # (nw's own dependency, imported lazily) and the caller's captured
        # context (e.g. reelee's BYO vision + ElevenLabs keys). ``nullcontext``
        # keeps the ``with`` shape uniform when either is absent.
        if captured_fal_key:
            from falaw import using_fal_credentials

            fal_ctx: AbstractContextManager[Any] = using_fal_credentials(
                captured_fal_key
            )
        else:
            fal_ctx = nullcontext()
        stop_beat = threading.Event()
        beat = threading.Thread(
            target=_beat_while_running,
            args=(rt, job_id, run_token, config, stop_beat),
            name=f"nw-jobs-heartbeat-{job_id[:8]}",
            daemon=True,
        )
        beat.start()
        try:
            # Innermost, so an explicit per-call key wins over an ambient one.
            scrubbed: BaseException | None = None
            with (
                fal_ctx,
                _provider_events(sink),
                extra_ctx if extra_ctx is not None else nullcontext(),
                using_secrets(secrets),
            ):
                try:
                    result = call()
                except BaseException as e:
                    # Classified HERE, on the live exception: what au persists is
                    # its text, which cannot say a refusal from a crash.
                    with rt.lock:
                        _index_update_locked(
                            rt,
                            job_id,
                            error_kind=error_kind_of(e),
                            error_detail=error_detail_of(e, secrets=secrets),
                        )
                    # au persists the RENDERED exception text as the job's
                    # error; a provider echoing the key back would put it in
                    # the store. `redact_exception` returns a rebuilt
                    # exception when the original's str() is not built from
                    # its string args. The rebuilt one is raised OUTSIDE this
                    # handler so the dirty original never becomes its
                    # `__context__` (a log integration walking suppressed
                    # context would otherwise still reach it).
                    scrubbed = redact_exception(e, secrets)
                    if scrubbed is e:
                        raise
            if scrubbed is not None:
                raise scrubbed
        finally:
            # ``finally``, not a trailing statement: a render that raises must
            # still stop beating, or a dead job keeps claiming to be alive and
            # the reaper it exists to inform never fires.
            stop_beat.set()
            beat.join()
        _reconcile_terminal(rt, job_id, result)
        return result

    return run


def _release_unentered(ctx) -> None:
    """Enter-and-exit a context manager no worker will enter.

    The one protocol that works for any context manager: a class-based one
    that acquired in ``__init__`` releases in ``__exit__``; a generator-based
    one just runs its setup and teardown once. Failures are swallowed — this
    is cleanup on a path that is already raising.
    """
    if ctx is not None:
        with suppress(Exception):
            with ctx:
                pass


def _capture_fal_credentials():
    """Snapshot the active fal credential (if any) to re-bind inside the worker."""
    try:
        from falaw import current_fal_key

        return current_fal_key()
    except Exception:
        return None


def _call_dispatch(
    callable_, project, params, *, job_id, on_event, should_cancel, secrets=None
):
    """Invoke the render callable, passing only the render-context kwargs it
    accepts (progressive disclosure: a plain ``f(project, params)`` works too).

    ``secrets`` is offered only when there is one, so a callable that predates
    the seam is called with exactly the kwargs it always was."""
    import inspect

    extras = {"job_id": job_id, "on_event": on_event, "should_cancel": should_cancel}
    if secrets is not None:
        extras["secrets"] = secrets
    try:
        sig = inspect.signature(callable_)
        if not any(p.kind is p.VAR_KEYWORD for p in sig.parameters.values()):
            extras = {k: v for k, v in extras.items() if k in sig.parameters}
    except (ValueError, TypeError):
        pass
    return callable_(project, params, **extras)


PROVIDER_PHASES = ("in_queue", "in_progress")
#: Statuses in which the worker is still running, so the provider's phase is live.
_LIVE = (RUNNING, CANCELLING)
#: Events that end a provider call: the phase it reported no longer holds.
_PROVIDER_CALL_ENDS = ("done", "error", "cache_hit")


def _provider_events(sink) -> AbstractContextManager[Any]:
    """Deliver the provider's own call events (falaw's ``ProgressEvent``) to ``sink``.

    Bound on the worker thread, so every fal call the job's render makes reports its
    queue position and phase without each layer between taking an ``on_event``. A falaw
    that predates ``falaw.events.listening`` just reports nothing.
    """
    try:
        from falaw.events import listening
    except ImportError:
        return nullcontext()
    return listening(sink)


def _mirror_provider_phase(
    record: Mapping, kind, fields: Mapping, updates: dict
) -> None:
    """Fold a ``provider_phase`` (and ``queue_position``) an event reports into ``updates``.

    An event that names no phase leaves the record alone: silence is not a phase.
    ``provider_started_at`` is stamped on the way INTO ``in_progress`` (not on every
    in-progress event), and the queue position is only kept while in the queue. With
    several calls in flight the phase is the LATEST report's.
    """
    phase = fields.get("provider_phase")
    if phase not in PROVIDER_PHASES:
        # A call ending (a result, a failure, a cache hit) ends its phase: the job is
        # doing local work, or waiting on its next call, not "filming".
        call_id = fields.get("call_id")
        if (
            record.get("provider_phase")
            and kind in _PROVIDER_CALL_ENDS
            and (call_id is None or call_id == record.get("provider_call_id"))
        ):
            updates["provider_phase"] = None
            updates["provider_queue_position"] = None
        return
    updates["provider_phase"] = phase
    updates["provider_call_id"] = fields.get("call_id")
    if phase == "in_queue":
        position = fields.get("queue_position")
        updates["provider_queue_position"] = (
            position if isinstance(position, int) else None
        )
    else:
        updates["provider_queue_position"] = None
        if record.get("provider_phase") != "in_progress":
            updates["provider_started_at"] = now_iso()


def _mirror_event_into_index(rt, job_id, ev) -> None:
    """Project a render lifecycle event into the index: progress, cost, cached,
    last_event_id, artifact_ref."""
    fields = _event_fields(ev)
    kind = _event_kind(ev)
    with rt.lock:
        record = _index_get_locked(rt, job_id)
        if record is None:
            return
        progress = dict(record.get("progress") or {})
        cost = dict(record.get("cost") or {})
        updates: dict[str, Any] = {}

        # Aliases, exactly as ``cost_map`` below does for ``cost_usd``: the
        # emitter owns its domain vocabulary, and the translation belongs at
        # this boundary rather than forcing every producer to spell the
        # store's field names. reelee's journey emits ``index`` /
        # ``transform``; without these two rows its whole stage breakdown
        # mirrored as nulls while every event was being delivered correctly —
        # a live defect that looked like "no events" from the outside.
        # Keyed by DESTINATION, with sources in precedence order — the
        # canonical name always beats its alias. A ``{source: dest}`` map reads
        # more naturally and is wrong: dict order decides, so an event carrying
        # both names would be resolved by whichever row happened to be written
        # last.
        progress_sources = {
            "stage_index": ("stage_index", "index"),
            "stage_count": ("stage_count",),
            "current_transform": ("current_transform", "transform"),
            "fraction": ("fraction",),
        }
        for dst, sources in progress_sources.items():
            for src in sources:
                if src in fields:
                    progress[dst] = fields[src]
                    break
        usd_sources = {
            "estimated_usd": ("estimated_usd",),
            "actual_usd": ("actual_usd", "cost_usd"),
            "cache_hit_savings_usd": ("cache_hit_savings_usd",),
        }
        if cost.get("estimate_source") == ESTIMATE_FROM_HOST:
            # The host priced this job server-side; the render's own guess
            # must not replace the figure it was approved at (nw#144).
            del usd_sources["estimated_usd"]
        for dst, sources in usd_sources.items():
            for src in sources:
                # A render is server code, but "None means unknown" holds for
                # its figures too: a NaN would poison every sum (nw#166). An
                # unusable one is skipped, so the field keeps what it had.
                value = _usable_usd(fields.get(src), what=f"a render event's {src!r}")
                if value is not None:
                    cost[dst] = value
                    if dst == "estimated_usd":
                        cost["estimate_source"] = ESTIMATE_FROM_RENDER
                    break
        # The unknown-cost flag travels with the figure it qualifies, or the
        # figure arrives alone and reads as exact.
        if fields.get("has_unknown_costs") is not None:
            cost["actual_is_lower_bound"] = fields["has_unknown_costs"]

        updates["progress"] = progress
        updates["cost"] = cost
        if kind == "cache_hit" or fields.get("cache_hit") or fields.get("cached"):
            updates["cached"] = True
        _mirror_provider_phase(record, kind, fields, updates)
        for src in ("last_event_id", "event_id", "id"):
            if fields.get(src) is not None:
                updates["last_event_id"] = fields[src]
                break
        for src in ("animatic_artifact_id", "artifact_id", "artifact_ref"):
            if fields.get(src) is not None:
                updates["artifact_ref"] = fields[src]
                break
        _index_update_locked(rt, job_id, **updates)


def _reconcile_terminal(rt, job_id, result) -> None:
    """Capture terminal payload fields (artifact, actual cost) the render returns
    but may not have emitted as events."""
    with rt.lock:
        record = _index_get_locked(rt, job_id)
        if record is None:
            return
        updates: dict[str, Any] = {"finished_at": now_iso()}
        if isinstance(result, Mapping):
            cost = dict(record.get("cost") or {})
            for dst, src in (
                ("actual_usd", "cost_usd_actual"),
                ("cache_hit_savings_usd", "cache_hit_savings_usd"),
            ):
                # The run's final figures, checked like its events' (nw#166).
                value = _usable_usd(result.get(src), what=f"a render result's {src!r}")
                if value is not None:
                    cost[dst] = value
            if result.get("has_unknown_costs") is not None:
                cost["actual_is_lower_bound"] = bool(result["has_unknown_costs"])
            updates["cost"] = cost
            for src in ("animatic_artifact_id", "artifact_id", "artifact_ref"):
                if result.get(src) is not None:
                    updates["artifact_ref"] = result[src]
                    break
        _index_update_locked(rt, job_id, **updates)

def _read_job(rt, record, config, *, project) -> Job:
    """Read one job: reap-if-stale, project, persist a grown pct floor, and
    announce a run seen terminal for the first time (:func:`register_terminal_hook`).

    Terminal-read consistency: a caller may hand us an index ``record`` snapshot
    taken *before* the worker mirrored the render's terminal fields (cost,
    artifact, finished_at), yet read the au store *after* the COMPLETED write.
    Because the worker commits those index writes strictly before writing the
    terminal au record, once we observe a terminal au status a fresh index
    re-read is guaranteed to include them — so a job observed ``succeeded`` never
    reports a stale/empty cost or a missing artifact_ref.
    """
    job_id = record["job_id"]
    run_token = record.get("run_token")  # the run this read starts from
    au_result = rt.au_store[job_id]
    au_result = _maybe_reap(rt, record, au_result, config)
    if au_result.status in _AU_TERMINAL:
        record = _index_snapshot(rt, job_id) or record
    job = _project_job(rt, record, au_result, config)
    if job.status in (RUNNING, CANCELLING) and job.pct is not None:
        if record.get("pct_floor") is None or job.pct > record["pct_floor"]:
            with rt.lock:
                _raise_pct_floor_locked(rt, job_id, run_token, job.pct)
    # The snapshot's run, not the re-read's: an ``enqueue`` between the two
    # replaces the run, and the status read here may be the old run's.
    _announce_if_terminal(rt, project, job, run_token=run_token)
    return job


_AU_TERMINAL = frozenset(
    {ComputationStatus.COMPLETED, ComputationStatus.FAILED, ComputationStatus.CANCELLED}
)


def _maybe_reap(rt, record, au_result, config) -> ComputationResult:
    """Reap a RUNNING record whose worker is gone (no live thread + stale start).

    A record that itself shows life (:func:`_shows_life`) is left alone without
    taking the lock, so polling a healthy running job never queues behind
    another replica (nw#158). Otherwise the reap is decided under ``rt.lock``
    on a fresh read of the record, not on the caller's snapshot (nw#159): the
    lock is cross-process (nw#148), so a heartbeat any replica stamped after
    the snapshot, or a re-enqueue (a new ``run_token``), saves the job, and
    au's status is re-read so a worker that finished meanwhile is reported,
    not reaped. The index is written before au's FAILED, the order a worker
    uses, so a reader that sees FAILED also sees the error; both inside the
    lock, so a re-enqueue cannot slip in between. What remains is a worker's own au write racing FAILED: au's window
    (nw#149). A record missing from the index has no fresher fact than the
    snapshot, so it is decided on the snapshot.
    """
    if au_result.status is not ComputationStatus.RUNNING or _shows_life(record, config):
        return au_result
    job_id = record["job_id"]
    with rt.lock:
        fresh = _index_get_locked(rt, job_id) or record
        if (
            fresh.get("run_token") != record.get("run_token")
            or _shows_life(fresh, config)
            or rt.middleware.is_running_locked(job_id)  # a live worker in this process
        ):
            return au_result
        current = rt.au_store[job_id]
        if current.status in _AU_TERMINAL:
            return current  # the worker finished after all
        # Under the lock, both writes: a relaunch happens only under it, so
        # FAILED can never land on a run that replaced the one reaped.
        return _fail_locked(rt, job_id, REAPED_REASON)


def _fail_locked(rt, job_id, reason: str) -> ComputationResult:
    """End ``job_id``'s run as FAILED for ``reason`` (caller holds ``rt.lock``
    and has decided): the index's error first, then au's FAILED, the order a
    worker uses, so a reader that sees FAILED also sees the error."""
    _index_update_locked(
        rt,
        job_id,
        finished_at=now_iso(),
        error=reason,
        error_kind=ERROR_KIND_CRASHED,
    )
    rt.au_store[job_id] = ComputationResult(
        None,
        ComputationStatus.FAILED,
        error=Exception(reason),
        terminal_reason=reason,
    )
    return rt.au_store[job_id]


def _shows_life(record, config) -> bool:
    """Whether ``record`` itself says its worker may be alive: a fresh
    heartbeat (from any process), or a start younger than ``stale_running_s``.
    Either only ever prevents a reap."""
    if _heartbeat_is_fresh(record, config):
        return True
    started = _parse_iso(record.get("started_at") or record.get("created_at"))
    return (
        started is not None
        and (_utcnow() - started).total_seconds() < config.stale_running_s
    )


def _heartbeat_is_fresh(record, config) -> bool:
    """Whether ``record``'s worker has beaten recently enough to be alive.

    ``is_running`` — the check beside this one — reads a **process-local**
    dict, so it answers "is a worker on this in MY process". A second API
    replica reading a job whose worker lives in the first replica gets
    ``False``, and once the record is older than ``stale_running_s`` it
    rewrites a healthy running job to ``FAILED("worker died")`` in the store
    they share. Silently, and to the record the live replica is also reading.

    That is invisible in a single process, which is why it would ship: at a
    few minutes per render the record never reaches the threshold, and only a
    long job crosses it.

    A missing ``heartbeat_at`` returns ``False`` — records written before
    heartbeats existed, and jobs whose worker died before its first beat,
    both keep exactly the old behaviour. This predicate can only **prevent** a
    reap, never cause one, so it cannot introduce a false positive of its own.
    """
    beat = _parse_iso(record.get("heartbeat_at"))
    if beat is None:
        return False
    return (_utcnow() - beat).total_seconds() < config.heartbeat_stale_s


def _beat_while_running(rt, job_id, run_token, config, stop: threading.Event) -> None:
    """Stamp ``heartbeat_at`` on the index record until ``stop`` is set, while
    the record is still this run's (``run_token``).

    Runs on a daemon thread beside the render. Best-effort throughout: a
    failed beat must never take down the render it is only reporting on, and
    a missed beat degrades to the pre-heartbeat behaviour rather than to a
    wrong answer.
    """
    while not stop.is_set():
        try:
            with rt.lock:
                _index_update_if_run_locked(
                    rt.index, job_id, run_token, heartbeat_at=now_iso()
                )
        except Exception:  # noqa: BLE001 — reporting must not break the render
            pass
        stop.wait(config.heartbeat_interval_s)


def _mark_worker_exited(rt, job_id, run_token) -> None:
    """Stamp ``worker_exited_at`` on this run's record. Best-effort: a missed
    stamp leaves a cancelled key held only until its heartbeat goes stale."""
    try:
        with rt.lock:
            _mark_worker_exited_locked(rt.index, job_id, run_token)
    except Exception:  # noqa: BLE001 — reporting must not break the render
        pass


def _mark_worker_exited_locked(index, job_id, run_token) -> None:
    _index_update_if_run_locked(index, job_id, run_token, worker_exited_at=now_iso())


def _worker_may_still_run_locked(rt, record, config) -> bool:
    """Whether a terminal-reading ``record`` may still have its worker running.

    Here, the process-local map answers. Elsewhere, only a cancelled job can
    read terminal while its worker runs (cancel is cooperative), and its worker
    proves it is alive with a fresh heartbeat until it writes
    ``worker_exited_at``. The exit marker matters because a heartbeat stays
    fresh ``heartbeat_stale_s`` after the thread is gone. On the managed
    backend the marker follows au's terminal write (nw#149); a backend without
    the middleware still has the gap between the worker's marker and that write.
    """
    if rt.middleware.is_running_locked(record["job_id"]):
        return True
    return (
        bool(record.get("cancel_requested"))
        and not record.get("worker_exited_at")
        and _heartbeat_is_fresh(record, config)
    )


def _project_job(rt, record, au_result, config) -> Job:
    """Pure projection of an index record + au result into a :class:`Job`."""
    cancel_requested = bool(record.get("cancel_requested"))
    status = _normalize_status(au_result.status, cancel_requested=cancel_requested)

    created_at = record.get("created_at")
    started_at = record.get("started_at")
    # Invariant (defense in depth): a job observable as running/cancelling/terminal
    # always has a started_at. The primary stamp is `before_compute`; here we
    # derive it from au's RUNNING-record `created_at` for any backend that might
    # write RUNNING without the index having caught up.
    if started_at is None and status != QUEUED and au_result.created_at:
        started_at = _iso(au_result.created_at)
    finished_at = record.get("finished_at")
    if finished_at is None and status in TERMINAL_STATUSES and au_result.completed_at:
        finished_at = _iso(au_result.completed_at)

    queue_wait_s = _duration_s(created_at, started_at)
    elapsed_s = _elapsed_running_s(started_at, finished_at)

    progress = _progress_from(record)
    cost = _cost_from(record)

    # Liveness, but only where the question means anything: a terminal job's
    # worker is *supposed* to be silent, and reporting that as lost contact
    # would make every finished job look broken.
    worker_silent_s = None
    worker_responsive = None
    last_beat = _parse_iso(record.get("heartbeat_at"))
    if last_beat is not None:
        worker_silent_s = round((_utcnow() - last_beat).total_seconds(), 1)
        if status in (RUNNING, CANCELLING):
            worker_responsive = _heartbeat_is_fresh(record, config)

    predicted_total_s = remaining_s = eta_s = None
    eta_ts = None
    pct = None
    confidence = label_hint = None
    eta_candidates = record.get("eta_candidates") or []
    eta_key = eta_candidates[0][0] if eta_candidates else None

    if status in (RUNNING, CANCELLING):
        prediction = predict_total_s(
            eta_candidates,
            record.get("output_kind"),
            durations=rt.durations,
            expected_cache_hit=record.get("expected_cache_hit", False),
            units=record.get("units"),
            config=config,
        )
        predicted_total_s = prediction.p50
        confidence = prediction.confidence
        pct, remaining_s, label_hint = _compute_pct_eta(
            elapsed_s or 0.0, prediction, record, config
        )
        eta_s = remaining_s
        if remaining_s is not None:
            eta_ts = _iso(_utcnow_plus(remaining_s))
    elif status == SUCCEEDED:
        pct = 100

    result_payload = None
    error = None
    error_kind = None
    error_detail = None
    artifact_ref = record.get("artifact_ref")
    if status == SUCCEEDED:
        if isinstance(au_result.value, Mapping):
            # au's store keeps a NaN as is; served, it would break strict JSON.
            result_payload = _finite_json(au_result.value)
            if artifact_ref is None:
                artifact_ref = result_payload.get(
                    "animatic_artifact_id"
                ) or result_payload.get("artifact_id")
    elif status == FAILED:
        error = str(au_result.error) if au_result.error else record.get("error")
        error_kind = record.get("error_kind") or (
            error_kind_of(au_result.error)
            if isinstance(au_result.error, BaseException)
            else ERROR_KIND_CRASHED
        )
        if error_kind == ERROR_KIND_REFUSED:
            # Only what the worker recorded, redacted, on the live exception:
            # the exception au hands back may be the unredacted original.
            error_detail = record.get("error_detail")
    elif status == CANCELLED:
        error = None
        error_kind = ERROR_KIND_CANCELLED

    return Job(
        job_id=record["job_id"],
        kind=record.get("kind", ""),
        label=record.get("label", ""),
        status=status,
        idempotency_key=record.get("idempotency_key", record["job_id"]),
        params=record.get("params", {}),
        created_at=created_at,
        started_at=started_at,
        finished_at=finished_at,
        queue_wait_s=queue_wait_s,
        elapsed_s=elapsed_s,
        progress=progress,
        predicted_total_s=predicted_total_s,
        remaining_s=remaining_s,
        eta_ts=eta_ts,
        eta_s=eta_s,
        pct=pct,
        confidence=confidence,
        label_hint=label_hint,
        eta_key=eta_key,
        cost=cost,
        cached=bool(record.get("cached")),
        # Only a running job has a live provider phase; a finished one reports the
        # moment it started, not a phase that ended with it.
        provider_phase=record.get("provider_phase") if status in _LIVE else None,
        provider_queue_position=(
            record.get("provider_queue_position") if status in _LIVE else None
        ),
        provider_started_at=record.get("provider_started_at"),
        worker_silent_s=worker_silent_s,
        worker_responsive=worker_responsive,
        artifact_ref=artifact_ref,
        result=result_payload,
        error=error,
        error_kind=error_kind,
        error_detail=error_detail,
        run_id=record["job_id"],
        run_token=record.get("run_token"),
        last_event_id=record.get("last_event_id"),
    )

def error_detail_of(
    error: BaseException, *, secrets: "Mapping[str, str | None] | None" = None
) -> dict | None:
    """The refusal ``error`` carries as data, or ``None``.

    Only a :class:`nw.GenreOpRefused`'s ``detail``, and only when it survives a
    strict JSON round trip (the job store persists it, and a NaN or infinity
    would make every response carrying the job unserialisable): a detail that
    does not is dropped rather than failing the job's bookkeeping. Every string
    in it is redacted of ``secrets``, as the job's ``error`` text is.

    >>> from nw.genres import GenreOpRefused
    >>> error_detail_of(GenreOpRefused("cap", detail={"limit_usd": 10.0}))
    {'limit_usd': 10.0}
    >>> error_detail_of(GenreOpRefused("cap", detail={"limit_usd": float("inf")})) is None
    True
    >>> error_detail_of(GenreOpRefused("x", detail={"echo": ["key=sk-1"]}), secrets={"fal": "sk-1"})
    {'echo': ['key=<redacted:fal>']}
    >>> error_detail_of(ValueError("bug")) is None
    True
    """
    from nw.genres import GenreOpRefused
    from nw.secrets import redact

    detail = (
        getattr(error, "detail", None) if isinstance(error, GenreOpRefused) else None
    )
    if not isinstance(detail, Mapping):
        return None
    try:
        data = json.loads(json.dumps(dict(detail), allow_nan=False))
    except (TypeError, ValueError):
        return None

    def scrub(value):
        if isinstance(value, str):
            return redact(value, secrets)
        if isinstance(value, list):
            return [scrub(v) for v in value]
        if isinstance(value, dict):
            return {redact(k, secrets): scrub(v) for k, v in value.items()}
        return value

    return scrub(data) if secrets else data

def error_kind_of(error: BaseException) -> str:
    """``"refused"`` | ``"cancelled"`` | ``"crashed"`` for an exception a job raised.

    >>> from nw.genres import GenreOpRefused, GenreOpCancelled
    >>> [error_kind_of(e) for e in (GenreOpRefused("no song"),
    ...                             GenreOpCancelled(), ValueError("bug"))]
    ['refused', 'cancelled', 'crashed']
    """
    from nw.genres import GenreOpCancelled, GenreOpRefused

    if isinstance(error, GenreOpRefused):
        return ERROR_KIND_REFUSED
    if isinstance(error, GenreOpCancelled):
        return ERROR_KIND_CANCELLED
    return ERROR_KIND_CRASHED




def _normalize_status(au_status: ComputationStatus, *, cancel_requested: bool) -> str:
    """au status ⊕ cancel intent → the 6-value job status.

    ``cancel_requested`` is authoritative: once the user cancels, the job reads
    ``cancelling`` (still in flight) → ``cancelled`` (terminal) regardless of
    whether the ``ThreadBackend`` thread later clobbers the au record with
    COMPLETED. A missing au key synthesizes PENDING → ``queued`` (membership is
    the index's job, not the au store's).
    """
    if cancel_requested:
        if au_status in _AU_TERMINAL:
            return CANCELLED
        return CANCELLING
    if au_status is ComputationStatus.COMPLETED:
        return SUCCEEDED
    if au_status is ComputationStatus.CANCELLED:
        return CANCELLED
    if au_status is ComputationStatus.FAILED:
        return FAILED
    if au_status is ComputationStatus.RUNNING:
        return RUNNING
    return QUEUED


def _compute_pct_eta(elapsed_s, prediction: _Prediction, record, config):
    """The §5.4 progress-% + remaining-seconds derivation (honest + monotonic)."""
    p50, p90, confidence = prediction.p50, prediction.p90, prediction.confidence
    label_hint = None

    if confidence == "prior":
        remaining = max(0.0, p50 - elapsed_s)
        return None, remaining, "estimating…"
    if confidence == "exact":
        remaining = max(0.0, p50 - elapsed_s)
        return None, remaining, "cached · instant"

    if elapsed_s <= p50:
        pct = (
            min(100.0 * elapsed_s / p50, config.pct_ceil)
            if p50 > 0
            else config.pct_ceil
        )
        remaining = max(0.0, p50 - elapsed_s)
    else:
        pct = min(90.0 + 9.0 * (elapsed_s - p50) / max(p90 - p50, 1.0), config.pct_ceil)
        remaining = max(0.0, p90 - elapsed_s)
        if elapsed_s > p90:
            pct, label_hint, remaining = float(config.pct_ceil), "finishing…", None

    floor = record.get("pct_floor")
    if floor is not None:
        pct = max(pct, floor)
    return int(pct), remaining, label_hint

def _index_get_locked(rt, job_id):
    return rt.index.get(job_id)


def _index_snapshot(rt, job_id, *, store=None):
    """``job_id``'s record (``None`` if absent) as one whole snapshot, **without**
    ``rt.lock`` (nw#158). ``store`` reads the archive instead (``rt.archive``,
    written the same way), default the index.

    The index is an :class:`AtomicJsonFiles`: every write lands by
    ``os.replace``, so a reader sees the old record or the new one, never a
    torn one, and the lock adds nothing to a lone read. Taking it anyway made
    every poll on every replica queue behind each other, and behind
    heartbeats, for as long as a full :func:`list_jobs` scan.

    Only for a read that no write depends on. A read-modify-write keeps
    reading inside the ``with rt.lock:`` that covers the write
    (:func:`_index_get_locked`).
    """
    return (rt.index if store is None else store).get(job_id)


def _raise_pct_floor_locked(rt, job_id, run_token, pct) -> None:
    """Raise run ``run_token``'s ``pct_floor`` to ``pct`` (caller holds
    ``rt.lock``), never lower it and never touch a run that replaced it
    (nw#170): two readers projecting different ``pct`` from their own
    snapshots would otherwise let the later, lower one win, and a reader whose
    snapshot predates a re-enqueue would hand the old run's progress to the
    new one."""
    record = _index_get_locked(rt, job_id)
    if record is None or record.get("run_token") != run_token:
        return
    floor = record.get("pct_floor")
    if floor is None or pct > floor:
        record["pct_floor"] = pct
        _index_set_locked(rt, job_id, record)


def _index_set_locked(rt, job_id, record) -> None:
    rt.index[job_id] = record


def _index_update_locked(rt, job_id, **fields) -> None:
    record = rt.index.get(job_id)
    if record is None:
        return
    record.update(fields)
    rt.index[job_id] = record


def _index_update_if_run_locked(index, job_id, run_token, **fields) -> None:
    """Merge ``fields`` into ``job_id``'s record only while it carries
    ``run_token``, in one read. Lets a run's own threads stamp its record
    without touching a run that replaced it. Takes the index mapping, so the
    middleware (which holds the index, not the runtime) uses it too."""
    record = index.get(job_id)
    if record is None or record.get("run_token") != run_token:
        return
    record.update(fields)
    index[job_id] = record


def _default_idempotency_key(project, kind, params) -> str:
    """``sha256(project:kind:basis)`` where basis is ``falaw.plan_hash`` of a
    supplied ``params["plan"]`` (plan-scoped dedup) or a stable hash of params.

    A plan that cannot be hashed is **not** silently deduped under a weaker,
    plan-blind fallback (nw#41) — that used to swallow *any* ``plan_hash``
    failure into ``json.dumps(_jsonable(params), default=str)``, a key that
    ignores the plan entirely. Two structurally different plans sharing the
    same other ``params`` then collapsed onto one key, and the second
    ``enqueue`` silently returned the first job instead of submitting its
    own — a dropped submission with no error anywhere. Since falaw 0.0.30
    (falaw#17) ``plan_hash`` raises ``FalNonCanonicalArgument`` for a
    genuinely non-canonicalisable argument, which made this reachable from
    ordinary caller input rather than only from malformed test data. The fix
    is the same "refuse loudly" contract falaw adopted: when a plan is
    supplied, its hash IS the basis, unconditionally — a plan that cannot be
    identified is not submittable, and the caller sees why.
    """
    plan = params.get("plan") if isinstance(params, Mapping) else None
    if plan is not None:
        from falaw import plan_hash

        basis = plan_hash(_plan_for_identity(plan))
    else:
        basis = json.dumps(_jsonable(params), sort_keys=True, default=str)
    blob = f"{Path(project.root).resolve()}:{kind}:{basis}".encode("utf-8")
    return hashlib.sha256(blob).hexdigest()


def _plan_for_identity(plan):
    """``params["plan"]`` as a :class:`falaw.Plan`, or a loud refusal.

    A job's ``params`` are JSON-serialized into the index, so a caller with a
    live ``Plan`` passes it through :func:`falaw.plan_to_dict` first — and that
    dict has to hash to the same digest the object would, or the same render
    submitted twice would dedup under two different keys and bill twice.
    Rebuilding it here is what makes both forms one identity.

    Anything that is neither raises, per this function's "refuse loudly"
    contract: a plan that cannot be identified is not submittable.
    """
    from falaw import Plan, plan_from_dict

    if isinstance(plan, Plan):
        return plan
    if isinstance(plan, Mapping):
        return plan_from_dict(dict(plan))
    raise TypeError(
        f"params['plan'] must be a falaw Plan or a plan_to_dict() dict, "
        f"got {type(plan).__name__}. A plan that cannot be identified is not "
        f"submittable — see nw.jobs._default_idempotency_key."
    )


def _jsonable(params):
    """Drop a non-serializable ``plan`` object from the params-hash basis (its
    identity is already captured via ``plan_hash``)."""
    if isinstance(params, Mapping):
        return {k: v for k, v in params.items() if k != "plan"}
    return params


def _default_label(kind, params) -> str:
    model = params.get("model") or params.get("application")
    pretty = kind.replace("_", " ").replace(".", " · ")
    if model:
        return f"{pretty} · {str(model).rsplit('/', 1)[-1]}"
    return pretty


#: The confidence tag of the shared, per-unit ``output_kind`` rung of the ladder.
_COARSE = "learned_coarse"


def _eta_units(params) -> int | None:
    """``params["units"]`` validated: a positive ``int``, or ``None`` when absent.

    >>> _eta_units({}) is None
    True
    >>> _eta_units({"units": 4})
    4
    >>> _eta_units({"units": True})
    Traceback (most recent call last):
    ...
    ValueError: params['units'] must be a positive int (the number of output_kind units the job covers); got True
    """
    if "units" not in params or params["units"] is None:
        return None
    units = params["units"]
    if isinstance(units, bool) or not isinstance(units, int) or units < 1:
        raise ValueError(
            "params['units'] must be a positive int (the number of output_kind "
            f"units the job covers); got {units!r}"
        )
    return units


def _eta_candidates(params, config):
    """Ordered ``[(key, confidence), …]`` ETA-key candidates (most specific first)
    plus the inferred output kind.

    A job declaring ``units > 1`` gets its own specific keys (suffixed
    ``|x<units>``), since its whole-job duration is not comparable with the same
    operation run once. ``units`` absent or ``1`` leaves every key as it was.
    The coarse ``output_kind`` key is per unit and never suffixed.
    """
    app = params.get("model") or params.get("application")
    tool = params.get("tool") or params.get("operation")
    units = _eta_units(params)
    if app and tool and units is not None and units > 1:
        tool = f"{tool}|x{units}"
    output_kind = params.get("output_kind") or _infer_output_kind(params, app, tool)
    dur_bucket = _dur_bucket(params.get("duration_s"), config)

    candidates: list[tuple[str, str]] = []
    if app and tool and dur_bucket is not None:
        candidates.append((f"{app}|{tool}|{dur_bucket}", "learned"))
    if app and tool:
        candidates.append((f"{app}|{tool}", "learned"))
    if output_kind:
        candidates.append((output_kind, _COARSE))
    return candidates, output_kind


def _infer_output_kind(params, app, tool) -> str | None:
    hay = " ".join(str(x) for x in (tool, app, params.get("kind")) if x).lower()
    if any(w in hay for w in ("video", "animate", "clip", "motion", "lipsync")):
        return "video"
    if any(w in hay for w in ("voice", "audio", "tts", "narration", "speech", "music")):
        return "audio"
    if any(w in hay for w in ("image", "panel", "still", "frame", "picture")):
        return "image"
    return None


def _dur_bucket(duration_s, config) -> str | None:
    if duration_s is None:
        return None
    edges = config.dur_buckets_s
    if not edges:
        return None
    if duration_s <= edges[0]:
        return f"<={int(edges[0])}s"
    for i in range(1, len(edges)):
        if duration_s <= edges[i]:
            return f"{int(edges[i - 1]) + 1}-{int(edges[i])}s"
    return f">{int(edges[-1])}s"


def _durations_get(durations: MutableMapping, eta_key: str) -> list:
    # Defense in depth, no longer load-bearing: since the store writes
    # atomically (reelee#298, :class:`AtomicJsonFiles`) a reader cannot catch
    # a sample write half-done. The guard stays for what atomicity cannot
    # promise — a record written by a pre-atomic version mid-upgrade, or a
    # hand-mangled file — where "no history" beats a crashed ETA query.
    try:
        record = durations.get(_safe_key(eta_key))
    except Exception:
        return []
    if not record:
        return []
    return list(record.get("samples", []))

def _safe_key(eta_key: str) -> str:

def _percentile(xs, p):
    if not xs:
        return None
    s = sorted(xs)
    if len(s) == 1:
        return s[0]
    k = (len(s) - 1) * p / 100.0
    f = int(k)
    c = min(f + 1, len(s) - 1)
    return s[f] + (s[c] - s[f]) * (k - f)

def _event_fields(ev) -> Mapping:
    fields = getattr(ev, "fields", None)
    if isinstance(fields, Mapping):
        return fields
    if isinstance(ev, Mapping):
        return ev
    if dataclasses.is_dataclass(ev) and not isinstance(ev, type):
        # A producer's own event record (falaw's ProgressEvent): its fields are the

        return dataclasses.asdict(ev)
    return {}


def _event_kind(ev):
    for attr in ("kind", "name", "type"):
        v = getattr(ev, attr, None)
        if isinstance(v, str):

    if isinstance(ev, Mapping):

            if isinstance(ev.get(k), str):
                return ev[k]
    return None


def _utcnow() -> datetime:
    return datetime.now(timezone.utc)


def _utcnow_plus(seconds: float) -> datetime:
    from datetime import timedelta

    return _utcnow() + timedelta(seconds=seconds)


def now_iso() -> str:
    return _iso(_utcnow())

def _iso(dt: datetime) -> str:
    if dt.tzinfo is None:
        dt = dt.replace(tzinfo=timezone.utc)
    return dt.astimezone(timezone.utc).isoformat().replace("+00:00", "Z")


def _parse_iso(s):
    if not s:
        return None
    try:
        return datetime.fromisoformat(str(s).replace("Z", "+00:00"))
    except (ValueError, TypeError):
        return None


def _duration_s(a_iso, b_iso):
    a, b = _parse_iso(a_iso), _parse_iso(b_iso)
    if a is None or b is None:
        return None
    return max(0.0, (b - a).total_seconds())


def _elapsed_running_s(started_at, finished_at):
    start = _parse_iso(started_at)
    if start is None:
        return None
    end = _parse_iso(finished_at) or _utcnow()
    return max(0.0, (end - start).total_seconds())
